# 工作区二次修正 · 2026-11-03

## 原因证据

主开发直接读取用户当前IAB，而非另开测试浏览器：

1. 用户标签页仍执行 `index-CJblbKWn.js` / `index-CJZgRfFg.css`，与服务端构建不同；实际侧栏190px、标题26px、表顶约370px。上次交付只检查了独立浏览器，没有更新用户已打开标签页。
2. 更新页面后发现经典滚动条差异：前期页heading宽895px、制作页910px，产生15px横跳。独立浏览器原先隐藏/覆盖滚动条，未复现这一问题。
3. 全局`:focus-visible`与文件导入标签使用2px outline加3px正向offset，造成外扩框。
4. 独立复审核实：生图包选中行后，旧viewport max-height规则优先级高于flex规则，留下约98px空白，只显示约3行。此项为本轮重要问题，已删除全部6处旧高度上限，交回复审。

## 修改

- `workspace`统一`scrollbar-gutter:stable`。实际用户浏览器中前期/制作heading均x220/y52/w895/h44；标题20px、导航12px、品牌16px一致。
- 统一44px顶栏与紧凑页头；删除重复副说明的可视占位，说明保留在标题提示；工作区横距16px。
- 脚本/生图包继续flex分配剩余高度，工具栏32px、脚本单元格上下6px；删除生图包6处旧viewport高度上限。
- 生产条件入口常驻顶栏，详情使用既有顶层Drawer，主体独立滚动、关闭按钮不随长内容滚走。既有说明和业务操作保留，不在表格下方展开。
- 外扩焦点框改为内部2px底线，深色区使用对应焦点颜色；复选框用内部指示。确认画风卡使用底色和确认标记，不加2px选中框。
- 脚本显示实际“共N格”，区分业务数据数量与可显示容量。实际当前话只有3格，没有新增业务数据。
