# 把已有戏剧信息转为镜头

本资料只用于已有脚本的视觉设计，不移植编剧工具或赋予镜头阶段改剧情权限。源方法来自编剧方法的蒸馏，不读取个人技能目录。

逐格辨认已有目标、阻碍、结果/转向：角色正在做、看、等待或试图得到什么；什么人/物/空间/信息阻碍；脚本已写出的结果或新信息。它们决定拍什么，不允许为了镜头补新动机、阻碍、台词、结果。没有动作、表情、对白或上下文支持的内心，不擅自变成新动作/表情，保留原稿并指出视觉依据缺口。

将已存在的信息变成可见证据：手部、停顿、姿态、视线、物品接触、距离、遮挡与反应。通过构图强调已有内容，不靠新增台词解释。源稿明确的表情幅度仍优先，不能把“更抓人”变成每格夸张表情。

节奏看两条轨道：外部情节松/中/紧，内部情感轻/中/重。情节松情感重可用空间、背影或局部反应；情节紧情感轻可用动作方向和信息层级。只改变视觉重心，不改事件。景别变化要对应功能，不机械远中近轮换或整话同一密度。

每格可有一个主要信息功能：建立空间、定位人物关系、展示已有新信息、反应、强化已有冲突、对照既有信息、留情绪空间、强调原有钩子。功能指导空白、遮挡、视线与裁切，不为了凑钩子新增悬念或转折。

连续性核对角色物理状态、已有情绪的可见表现、已知信息、当前目标，以及衣装、伤势、发饰、道具、视线锚点；场景核对固定结构、已公开物品和线索、前格留下的画面关系。此记录用于防穿帮，推断不能写回原著或已采用脚本。场景开头承接/建立空间，中段推进已有冲突，结束接已有结果，不新增情节。

用户在脚本编辑阶段明确要求增删改时走宿主独立修改候选；镜头/视觉阶段继续使用固定脚本，不让镜头规则封死已授权脚本编辑，也不借此自动改稿。
