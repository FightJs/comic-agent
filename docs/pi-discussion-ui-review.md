## 资料列表初审问题与复审结果（已解决）

### 初审重要：第101项后的资料无法明确附加 → 已解决

位置：脚本/生图包 AI 助手 → 本次资料 → 新建讨论。复现：当前阶段有超过100条记录；本次浏览器隔离样本为121个生图包。现象：只渲染前100项；滚动到最后仍只有第100话；没有资料搜索、翻页或“仅展示前100项”的说明。影响：长篇制作中后续话格无法通过资料选择器绑定精确版本，用户只能依赖自由文字和模型自行查询，不能完成该控件承诺的明确选择。建议：对全部候选支持搜索或分页，选择上限仍可维持100项并明确说明。

证据：`output/playwright/pi-ai-package-manyrefs-1280.png`、`output/playwright/pi-ai-package-lastref-1280.png`；Playwright实际读取100个 checkbox，末项为“第100话第1格 · 长名称资产版本与人物连续性确认说明 · v1”。

### 初审一般：资料项 checkbox 与名称上下居中，密度低 → 已解决

位置同上。大量候选展开后，每个 checkbox 位于独立上一行，长名称居中下一行；200px列表视口仅能显示约3项。建议资料 label 显式使用横向布局、顶部对齐与左对齐，名称自然换行。截图同上。
