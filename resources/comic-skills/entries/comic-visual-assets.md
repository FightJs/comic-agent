# 条漫画风、人物与场景资产（工作台移植）

适用于画风基准、身份/衣装/场景核对、准确参考选择、缺失资产提示词及重生成候选；不在此重写剧情或直接开始正文批量生图。先读[工作台合同](references/workbench.md)，对适用对象使用[一致性规则](rules/MEM-005.md)。

1. 对照原著与当前已采用脚本确认称呼、身份关系和本次可见状态；保留原称呼，不给未命名角色编全名。资产存在不等于正确人物/衣装/场景，必须核对实际批准依据；未看清时保留缺口。
2. 人物板证明身份与衣装，场景参考证明布局，批准漫画样例证明画风。分别说明用途；构图图、失败图及相似房间不能覆盖这些权威。选择具体子空间和实际方向，不能只凭颜色判同场景。
3. 衣装与关键配饰记录款式、层数/数量、人物自身佩戴侧、身体锚点或手指，以及清晰来源和真实裁区；低清与遮挡不证明不存在，未知不默认左右对称。参考应足够看清本格必要细节；插值放大不创造证据。
4. 已有批准状态覆盖则复用；缺视角/状态只补缺项，真实单次物件可在提示词准确描述。只有本批确需持续复用或用户要求才做完整资产；不为旧索引无关缺项生成多余图，也不宣称已核对全书。
5. 临时或长期人物衣装参考同样要求独立全身主图及正面0°/真侧面90°/背面180°三视图，头到鞋完整、纯白空白背景、身份衣装与配饰一致。完整人物卡沿本书批准版式，状态增量不能替换既有身份；不要将两个角色混成一张身份板。
6. 场景板沿实际批准模板（不强制九宫格），保持建筑连接、固定物件与光向；多视图来自同一场景关系。版式合格不证明空间正确，生成候选也不授予入库或采用。
7. 给出可直接使用的提示词：具体目标状态、保持的身份/画风/布局、必要视图与背景、实际参考用途和不可变约束。若用户要求重生成，先说明本次变更与保护范围，通过已有图像预览/启动入口执行；没有对应工具时只提交提示词候选，不声称已经生图。

输出准确的本批可用依据、必要缺项与候选提示词；保留既有项目资产记录，不创建第二套权威索引。画风探索与当前已批准画风分开，未经采用的方向不能悄悄进入正文。
