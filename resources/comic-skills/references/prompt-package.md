# 最终绘图提示词：本格事实与去冲突

提示词依据本次已采用脚本和固定资产，不以长篇理论、审批元数据或旧工具字段代替画面。先查[身份](identity-confirmation.md)、[取景](shot-framing.md)、[参考用途](reference-continuity.md)，缺依据准确说明，不能模糊措辞掩盖。

建议顺序：明确画幅/机位/身体裁切/可见边界；人物身份、当前衣装及可见细节和画面位置；表情、头身方向、视线、动作阶段；必显接触、承托、物件与真实遮挡；背景模式、批准色调/光向及保留省略；重点清晰对象和批准画风；按真实数组编号的参考职责。同一事实合并一次，不重复附整套通用禁令；必要约束完整保留，不为长度目标截断长动作或细节。

正文只描述实际入画内容。画外人物/道具和源脚本原文保留在项目资料，不粘成额外绘制要求。全身角色板不授权补腿脚，宽景板不要求整房间。相邻镜头差异的推理留方案，正文执行本格，不写机械“必须换景别”。对白、心声和后期SFX与画内文字区分，不把后期气泡当场景招牌生成。

手部写角色自身左右、任务、物件部位、指掌包围与拇指对握、腕臂所属及当前接近/接触/接稳阶段。真实遮挡不强求五指全露；不能只说“手指完美”。自然持物靠实际裁切突出，不强行举向观众。肩髋膝脚与承托形成可行姿态；同一手不可同时执行互斥任务。双人接触写作用对象及具体部位，扶前臂不能画成抓上臂，靠近不能冒充握住。

分别说世界位置、画面位置、头向、视线目标；目标在画外不补入场。物件正面朝使用者时，摄影机只能见到对应侧/背面，读屏需要可行机位。信息箭头/无线图标是表现选择，不自动变成物理连线。可见首饰按来源写结构、层数、连接、佩戴侧和手指，不把同色当同款，遮挡不改身体归属。

参考用途明确允许/禁止迁移，按最终实际图片顺序编号。只有真实可用且已核定的参考才写入，不留空构图槽，不声称路径名字已上传。不支持的seed、权重、区域硬锁或negative_prompt参数不得虚构；必要避免事项写入宿主支持的最终提示词。工具能力和[参考预算](reference-budget.md)同时成立才可提出执行计划。

一次审最终将发出的完整内容，清掉互斥旧句：胸上却要膝上动作、保清晰必要场景却强散景、手势必显却手出画、全身板覆盖具体裁切、资产默认表情覆盖脚本睁眼/微张嘴。不能只改某一处文字留下其他正文冲突。源脚本与采用状态不动；修正权威候选及对应受影响包版本，重新走现有采用/预览入口。

返修明确实际缺陷、区域、删除旧结构/替换新结构/接续位置，同时保留正确身份、衣装、动作、空间、光向和既有修正。底图必须为本格真实返回，错误要素不能当作权威。返回再看修复与未授权变化，“修改版”文件名和编译成功都不是视觉通过。

普通讨论可给准确prompt与修改候选，不能因为写好了prompt就宣称已生成图片。当前宿主没有旧prompt.txt/manifest编译器与旧CLI；本资料不授予执行权限，不虚构输出字段已生效。
