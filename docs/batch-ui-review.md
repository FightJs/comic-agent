## 结论

**核心界面工作流通过独立审查**：脚本范围生成、选格讨论与候选采用、结构化生图包及多图讨论/生成/逐项采用可完成；本轮发现的五项重要问题均经修复与浏览器复验关闭。AI 结果始终标注模拟，模拟审核不放行正式生产。一般体验问题也已修复，仍有下述未验证范围，不应将本结论解释为全部验收条款无条件完成。

## 实测闭环

1. 从细纲生成第3话；选择9–11话跨批次生成；缺失第31话明确拦截。讨论消息不创建生成任务，显式生成后产生候选，原脚本保持不变。逐格采用只更新选中原始ID，其他格版本不变。第11话两格结果可在同一宽对话框连续比较。
2. 300格长表：11列横向滚动，冻结格号和表头，多行台词/备注完整换行；1280px无页面级横向溢出。深处话号定位建议已反馈，最终样例第3话冻结格号已显示“3话 / 01格”，300格末端最新改动未重复截图。
3. 生图包绑定脚本准确版本及资产采用版本（资产head为v3、采用为v1时绑定v1）；分段编辑联动完整提示词，手动覆盖后后续分段编辑不覆盖手工全文。最终提示词、执行参数、前图依赖、检查目标均具可访问名称。
4. 图片点/框区域文字可保存，边缘弹层保持画布内可用；两个新增区域经刷新和服务重启恢复。多图共同要求与逐图要求可提交，任务绑定底图与标注版本；同组两格结果并排原稿/候选，采用其中一格不改变另一格。
5. 部分失败及单项重试：经明确授权，在隔离数据库将一个已完成子任务改为失败，浏览器展示仅该格重试；重试产生新输出，另一成功格输出不变。此为人工注入异常验证，不是模型自然失败。
6. 对讨论返回施加700ms延迟，发送后继续输入下一条消息及手工方案：响应回来后二者保留。测试拦截已移除。
7. 200%实际缩放：区域侧栏入口可定位画布弹层，输入和完成/取消可见；讨论输入可经纵向滚动到达。不是完整200%全流程覆盖。键盘Enter打开已有区域批注已测试。
8. 重启后选第3话两格点击“通过所选版本”：仅选中两格显示已通过，第三格仍待审核；明确提示“模拟内容不能正式放行”，正式关口仍显示缺件。

9. 最终历史入口补验：两张当前采用均为v3时，展开“查看历史底稿讨论”，可定位 `1话1格 v3 / 2话1格 v1` 原讨论及模拟回复；展示“历史讨论只读，不会加入当前生成方案”。历史区没有输入或操作按钮，展开前后当前未发送消息和手工方案均保持原值。
