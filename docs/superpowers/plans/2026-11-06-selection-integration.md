# 文档精确选段接入增量

原批准依据：2026-11-05-pi-integration.md阶段四选格/选段修改与阶段七候选确认；本文件记录实现选择，不另改产品范围。

- 沿用现有阶段讨论与propose_changes。选段会话固定单一已保存骨架/细纲、版本、UTF-16文本偏移和原文；不允许全稿record修改或图谱/脚本操作绕选区。相同文字靠位置区分。
- 模型patch.text只为选段替换纯文本。保留不可变候选/来源/完整回复关口/取消及额度续接，讨论不写稿。
- 浏览器以原ProseMirror范围生成合法富文本；采用请求提交该HTML，宿主核对目标版本、原选区与新全文平面文本严格等于固定替换。只取服务器原非HTML字段，来源由候选继承。客户端还核对完整原编辑HTML，任一局部编辑均先阻止。格式由现有编辑器变换保证，服务端强制选区外文字不变；该接口和人工编辑一样接收用户确认的HTML，不授模型HTML或任意字段写入权限。
- 不采用按字符串首次命中替换（重复文字会错位）；不让模型返回整篇HTML（无法保证只改选段）；采用编辑器已有位置变换与宿主文本范围校验，无新增解析依赖。

顺序：后端范围/权限/采用RED→实现；前端选择/候选/明确采用及冲突验证；真实Pi SDK本机替身闭环；全量验证；独立代码与ui_reviewer实页复审；更新操作和交接。尚未执行步骤以docs/pi-progress.md为准。选段跨段落/粗体/列表/emoji与重复文本均需验证，不能以单段样例替代。
