# Pi 调用检查点与讨论续接

2026-11-06：已实现持久登记、只读查询及**干净额度检查点的阶段讨论与文本生产明确续接**。文本生产干净额度检查点已接入；手动暂停后端与界面已接，新增界面独立验收见下方记录；未决回执恢复与真实长篇压缩语义质量仍未闭合。本页不是断电耐久或真实供应商验收。

## 当前边界

`run`（讨论及文本生产）在 `data/agent/<project>/checkpoints/<run>.json` 保存私有账本。目录700、文件600；登记文件创建使用排他写入，后续用临时文件、fsync及原子替换。每次初始化同步完整目录祖先链，包含上次同步失败留下的目录；任一步失败均不开始后续外部调用。账本文件与现有Pi会话均应随完整data目录停服备份，不能单独删除账本来恢复运行。

一次运行最多登记20次模型请求、50次有效宿主工具派发：

- 模型调用的登记在共享适配器发出请求之前同步持久化，包含SDK自动压缩所用模型请求，不再只数可见回复轮次。登记是发出前预留，不等于供应商已接收或已计费。
- 工具派发前记录调用ID、工具名和参数hash，收到宿主回执后标为received/rejected；未收到回执保留未决状态，不假称已完成。
- 同运行编号一旦有账本，重启、换密钥或重复请求均不能重新开始，不会自动换新编号绕过额度。已完成的答复和候选沿用原保存流程。
- 用量按实际返回累计，自动压缩用量也计算；缺用量或仍未返回的登记标为未知，金额保持null。错误终止也能返回已知完整用量；部分已知用量只在检查点中明确保留，不冒充完整总量。
- 保存SDK会话文件相对位置、开始/当前leaf及固定输入hash，供后续核对与明确续接使用。账本不保存prompt、工具正文、配置密钥或供应商错误正文；会话本身仍按原约定保存业务讨论内容。

额度触发后，内核账本为paused；新增讨论将业务状态也保存为paused。用户不能在同会话直接发新消息或换附加资料绕过额度；可以先结束暂停；若附加原稿已有新版本，普通新消息会在建任务前提示更新资料，更新后再发送，不会反复建立中断任务。原输出、回执及候选保留，暂停候选不能直接采用。旧failed/interrupted记录不伪造为可续接状态。

`setup`仍使用无会话落盘的8次模型/目录工具上限；`complete`（图谱/视觉）仍为无会话单次调用，分别沿用原Python任务或视觉账本。它们不伪装成20轮可恢复运行。

## 阶段讨论的明确续接

在阶段AI助手，暂停记录展示本段模型/工具登记数。核对后勾选“授权新增最多20次模型请求和50次工具派发；费用未知”，再点击“明确续接此检查点”。这会创建唯一关联的child运行，父记录标为continued；每段仍不超过20/50，不会自动再开新段。重复点击/网络重试返回同一个child，不重复授权或派发。旧候选不会转移成已完成、自动采用或人审通过。

续接绑定原编译请求、规范化的公开供应商配置、工具权限、原会话文件及准确leaf；使用SDK open+branch，不采用“最近会话”或后来的分支。重新注入原任务、原固定资料与原权限。密钥只在实际发送前重读，换公开型号/地址/协议需重新讨论。继续操作不会把输入框里尚未发送的新意见偷偷提交；该草稿保留。

宿主在采用续接授权及出队提交前均复核：附加可写资料write_refs的当前版本、固定原著解析/来源、图谱及已启用的阶段Skill。未附加资料仍只按原冻结历史版本读取，不称项目全部head均不得变化。调用读到mock来源时，后续段继续继承mock，不能洗白。源/输入变化则拒绝，用户可结束暂停后另行处理。

只允许已保存会话、无未返回模型、无未决工具的额度暂停。未知在途、旧无原请求快照、旧绑定格式或其他失败不自动恢复/重放。Node父账本也只允许绑定一个child；异常中断不自动分配新编号。完整未决回执对账及其他生产故障恢复仍需后续实现。

业务API：

```
POST /api/projects/{project}/agent/runs/{run}/continue
{"expected_version":1,"confirm":true}
```

严格拒绝额外字段、非布尔confirm和未授权请求；会话版本及父子关联在SQLite事务内核对。续接链分别保留原段用量/账本，并汇总所有段已知tokens、未知段数；有部分用量的段，其已知值仍计入，但未知标记不会消失。金额始终未知，不是全局token/金额预算。

## 只读查询

内部协议 `checkpoint` 与health/cancel一样不等待模型容量，不读取密钥、不调用模型、不创建缺失目录或补写计数。进程被杀后，原running账本查询返回 `interrupted=true`，不把未知结果标成失败或免费。

业务API：

```
GET /api/projects/{project}/agent/runs/{run}/checkpoint
```

先以现有数据库校验项目和运行归属，再向Pi查询。旧运行缺账本返回404并说明历史未记录；运行层不可用返回503；归属/格式异常拒绝，不返回原始异常或供应商正文。响应含checkpoint状态、模型登记数/20、工具数/50、未决工具数、未知用量次数、用量完整性及是否保存会话指针，不暴露会话文件路径。

## 文本生产的明确续接（2026-11-06）

骨架、细纲、脚本生成/修改及生图包文本生产达到20模型/50工具上限时，任务保存为paused，部分输出不生成候选，不自动进入第二次结构修正或普通重试。结果页显示“额度暂停”、本段请求数与明确授权入口；可取消暂停。只在原会话已保存且无未返回模型/未决工具时可继续。未知、普通失败及旧无原请求快照不伪造续接。

用户勾选新一段20/50授权后，仍使用同一生产任务、原system/prompt/公开配置、固定资料与准确SDK分支。新增唯一child运行段，重复点击/网络重试返回同一child，不重复派发。结构尝试数沿用原1或2：额度续接不新增结构修正次数，即使第二轮结构尝试暂停后续接仍无第三次机会。每段再次到限仍暂停，下一段另需明确授权。

生产请求快照存production_requests，检查点存production_checkpoints，父子关系存production_continuations，均随SQLite完整备份；请求不含配置密钥。工具查询记录、读到的输入版本/图谱及mock来源在暂停前持久化，续接不洗白。回执按运行段列出，部分已知tokens仍标总量未知。普通retry不适用于已有额度检查点或续接链的任务。

授权时及出队发送前复核输入版本、批准参考的当前采用/审核状态、原著解析/来源、图谱、项目偏好、阶段Skill和公开型号/地址/协议；密钥实际发送前刷新。输入变化拒绝续接，授权选择和原稿保留，可取消暂停后重新核对。新意见不会通过继续按钮提交。暂停任务保留冲突范围占位，避免同话格另发重复生产。完成输出仍为未采用候选，沿原采用/审核关口。

{"confirm":true}

GET任务attempts返回本段checkpoint、parent/child及独立usage；不返回原请求system/prompt、会话路径或密钥。授权失败/容量等待失败不会自动换编号，已提交但未知的恢复仍须后续专门对账。本轮只支持干净额度暂停，不能称所有生产attempt故障或完整会话恢复完成。

## 自动压缩后的原任务重注入（2026-11-06）

真实SDK的长工具循环在截断输出后会自动压缩再重试，压缩可能移除当前原始user任务。运行层现在只对本次session的正常模型请求检查完整原任务：原文仍在时不重复；已移除时补回本run保存的原始编译prompt（含宿主原固定索引/规则/偏好/输出schema）。明确续接也补回同一原任务与续接授权说明。补回以user数据形式传递，不把原著或Skill提升为system权限，不信任摘要替换版本或授权。

SDK摘要请求使用独立路由，保留其原摘要上下文；重注入只改变当次发出的请求，不追加会话历史、不改检查点输入hash、不发工具、不扩大工具数组、不重新授予额度。后续每次正常请求若任务仍已被压缩，仍补原文；新运行使用新编译输入，不沿用上次补回内容。原20/50计数包含摘要和retry，原版本/采用/审核守卫仍由宿主执行。

固定输入仍受原200000字符请求上限约束。若完整原输入加保留上下文超过供应商窗口，可能继续失败，沿原错误/返回保存流程处理，不静默截断、换型号或新建额度。本轮只证明传递保真与权限边界，不证明摘要对长篇人物/事件语义无损。

```

{}
POST /api/projects/{project}/production-jobs/{task}/pause
{}
```

请求体严格为空对象，不接受confirm、start_paused或自选运行编号等额外字段。宿主先将暂停意图写pi_pause_requests，再通知原运行；重复暂停不产生新模型请求。讨论返回原run及pause_requested，生产返回任务状态及pause_requested。**暂停意图已保存不等于已经暂停**：状态仍running时当前调用可能正在返回，须查询最终paused/completed/interrupted状态。终态请求不重开运行；图像、模拟任务和无会话setup/complete调用不通过这些文本暂停接口执行。

pi_pause_requests为SQLite增表，无密钥/正文；正常重启保留已暂停状态及意图，仍需完整data备份。应用在已提交调用中断电并非本轮可恢复证明，真实未决回执核对仍未接完；不能删除Node账本来重试原run。

## 2026-11-06：检查点回执完整性

读取或续接持久检查点前，运行层校验模型请求/返回/已知用量响应计数的整数范围和顺序、工具回执编号唯一性、已登记工具名/状态/输入摘要及用量字段。缺字段、负数、超计数、未知工具状态等返回完整性错误；原文件保留，不补零、不改成干净检查点，也不会因为查询再次请求模型。

讨论续接的业务入口也严格要求session_saved=true、两个未决计数均为整数0，缺失或类型错误不构成授权。历史不完整账本会被拒绝，需要核对原件与完整备份；这不是迁移修补或未知调用恢复功能。正常检查点、自动压缩和明确续接继续使用原有预算与分支。

## 2026-11-06：工具回执关联与只读核对

讨论及Pi文本生产的新工具请求携带Node对实际JSON参数计算的SHA-256。宿主另存语义输入摘要，两者含义不同，不用Python重算结果假称同字节。新增`pi_tool_receipts`按项目/讨论或生产/运行段/调用编号关联；原业务写入、原工具审计和新回执在同一SQLite事务。相同编号及输入复用原结果，参数或摘要冲突拒绝；旧无编号调用仍走历史路径，旧审计不补造新回执。

Python以现有`ensure_ascii=False`序列化结果原串作为`result_json`传给Node。Node先验证它与data表示同一JSON值，再记录原串SHA；未带原串的旧调用标为local_json，不冒充可与宿主匹配。检查点只存摘要/状态，不存结果正文。逐条详情仅输出固定字段，即使账本多了未知字段也不透传。新增可选会话leaf和assistant_leaf：仅当前SDK持久分支包含同一assistant消息对象且调用id/name/参数准确匹配时记录assistant_leaf；无证据时不猜测。

只读接口：

- `GET /api/projects/{pid}/agent/runs/{rid}/tool-receipts`
- `GET /api/projects/{pid}/production-jobs/{tid}/attempts/{aid}/tool-receipts`

内部使用`checkpoint_details`，不调用供应商、不派工具、不创建或改写检查点；接口先校验项目与运行归属。返回`matched`、`host_saved_node_unconfirmed`、`mismatch`、`unverified`或`missing_or_legacy`。匹配只证明登记一致，不证明内容正确或工具业务成功；记录缺失也不能证明没有执行。SQLite与运行层文件依次读取，运行中的对账是可能变化的快照，不能将短暂不一致作为恢复或重放授权。检查点缺失/损坏返回409，不伪造状态。仅返回调用编号、工具名、状态与存在性，不返回正文、会话文件路径、密钥。

以上为只读关联批次的历史边界；后续受限显式恢复见下节。旧干净暂停仍沿原明确20/50新段授权。

验证与限制见`docs/pi-progress.md`。真实SDK/本机替身已核对实际assistant entry、正常matched及模拟丢确认的只读状态；模拟是在合成临时账本上移除收到标记，不冒充实际断电或真实供应商恢复。无前端改动，不沿用旧UI评分。

## 2026-11-06：已保存工具结果的显式恢复

适用讨论、精确选段讨论及Pi文本生产：原运行已停止，模型返回完整，最后一个assistant工具组每条调用都有宿主事务回执和准确SDK分支证据。先点“核对工具回执”，可核对时勾选“仅补回已保存结果，不请求模型或执行工具”，再明确补回。原SDK文件追加标准工具结果，保留原检查点快照、计数与未知用量；恢复落干净暂停点，不创建模型运行。随后继续仍须单独明确20模型/50工具新段授权，默认未选。恢复不等于人工采用或审核通过。

- 讨论：`POST /api/projects/{pid}/agent/runs/{rid}/recover-tools`，严格`{confirm:true,expected_version:会话版本}`。
- 生产：`POST /api/projects/{pid}/production-jobs/{tid}/attempts/{aid}/recover-tools`，严格`{confirm:true}`。
- 原GET tool-receipts附带可尝试恢复状态和脱敏恢复元数据。可尝试不代表Node已验证分支；最终校验失败保留原件，不发送工具或模型。

恢复认领与原审计精确核对，固定恢复ID和持久会话锁。请求失败或断线后可重试同一恢复，不换编号重新执行；原运行取消优先，过期输入仍拒绝。失败后“结束本次恢复”明确取消原运行并解除锁，保留历史与未发送意见，不自动取消或续接。讨论新消息/改绑/续接、生产普通retry均不能绕过锁。

限制：未知模型请求、旧无摘要/分支、缺宿主结果、缺原会话文件、错误摘要、多个不确定工具组或后继assistant等继续拒绝。工具业务本身的错误结果即使完整补回，也不算业务成功。本轮支持安全可证明的已存结果，不宣称任意中断自动恢复。代码`tool_recovery.py`/`recovery_service.py`/`agent-runtime/src/tool-recovery.mjs`；真实SDK杀进程及页面证据见`docs/pi-progress.md`。
