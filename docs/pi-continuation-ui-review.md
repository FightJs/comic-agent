## 问题（按严重程度）

### 重要：结束暂停后同会话普通消息连续中断

位置：脚本审核AI助手，session `5b01efc13cd74ed4b0a2f01ac6acfe73`。
复现：新讨论附加第1话第1格v1，UI发送“【额度暂停验收】附加脚本版本冲突审查”；实际暂停后通过本机隔离API将该脚本改为v2；勾选明确续接得到409；关闭重开确认草稿仍在，点击“结束这次暂停”；随后UI发“独立审查结束暂停后的新消息”，再发“独立复核结束暂停后普通消息，请答复。”。
现象：两次均“已中断 / 运行中断；请核对后重新发送”，没有答复。第二次无关闭或切换操作。暂停已解除、按钮可用，但恢复主要流程不可用。
影响：用户按界面建议结束暂停后仍无法继续讨论，重试也失败。
建议：检查运行层结束暂停后的会话/检查点和SDK历史恢复，保证普通新消息建立合法新运行；异常须给出可行恢复路径。
证据：`/tmp/pi-continuation-1280-after-cancel-interrupted.png`，API保存同会话3条运行，第一条cancelled、后两条interrupted。原因尚未定位，不能仅据界面推断是SDK缺陷。

### 一般：取消暂停仍显示旧轮次错误

位置/条件：上述会话结束暂停后旧记录。
现象：“已取消”下仍为红框“已达到单次模型轮次上限，请检查当前结果”。
影响：难区分用户已结束与仍待处理的额度故障。
建议：取消后清理旧错误，或明确显示“用户已结束额度暂停，原记录保留”。同上截图。

### 一般：授权checkbox与文案分成上下两行

位置：暂停检查点，两个实测宽度均可见。
现象：小方框独占一行，长授权文案下一行开始；增加垂直空间且弱化勾选和具体授权范围的关联。
建议：将文案放入span并与checkbox保持水平flex，长文案仅在文字列换行。现有label可点击、控件具有完整可访问名称，因此非阻断。
证据：1440-paused、1280-long-paused、1280-conflict截图。
