# 同组三套画风测试

2026-11-06增量。Pi可提出三套固定内容的二维画风方案，逐套或整组预览，明确授权后连续生图，结果并排比较。原模拟三套仍为单独演示入口。真实供应商的视觉质量、身份稳定性及测试板效果尚未实测。

## 操作

1. 导入并解析小说，采用、审核当前细纲。到“画风”点击“AI三套画风方案”，请AI先阅读原著与已审核细纲，为同一主角、同一主场景提出三套画风。
2. 回复中打开“查看三套画风方案”：核对共同人物/外观/场景/环境/动作、固定细纲版本和宿主读取的原著引文，再比较A/B/C的线条、比例、上色与阴影。引用只能证明这些原文存在，不能证明AI补充外观或动作正确；没有读取全书时不得声称全书通读。
3. 每套是一张覆盖身份、多视角、表情和剧情场景的测试板。点对应方案的“预览”，核对固定型号、完整提示词和实际参考，再点“确认并生成1张”。也可点“预览整组三张”，核对三套固定提示词、型号/尺寸/数量，勾选明确授权后连续生成。整组最多3次业务生图；首次预览可额外明确0–4次确认未发送技术重试，公开最多3×(1+额外次数)次物理网络尝试，不含视觉检查；未知、已响应或拒绝不重试；模型提出方案和查看方案不生图。已有任一套单独提交后，不能再装作一份新的完整三张授权。
4. 生成后回到三方案并排查看实际保存返回，点各方案的图像任务核对候选、拒绝或明确采用；未采用前不进入主表，采用后仍待审核，画风确认须另行完成。刷新后在原讨论历史中重开测试组。后来采用普通重生成图时，旧组保留原测试返回，并标明它已被新版本替换，不把旧返图误称为当前采用。
5. 未知结果先核对原调用，可沿原单图任务恢复已存返回或登记人工结论，不能重复生图。输入变化后原组/原返回保留，未提交任务不能用旧授权继续生成；重新讨论不会把旧组迁成新依据。

## 固定输入与权限

工具propose_style_tests仅对新style运行显式开放，旧tools=true或旧显式白名单不扩权；旧检查点续接仍保留原权限与额度。它只接受一份固定已采用审核细纲、首选原著解析版本/字符范围、共有内容和恰好3个方向，不接受模型、URL、密钥、目标图或脚本。

原著引文由宿主按Unicode字符坐标读取，人物/场景名称须在引文中定位；每次最多5段，沿现有每段10000/合计30000字符界限。已重解析或原件记录版本变化时不能在旧讨论中改绑。三个方向不能只换名称，宿主重复相同共有输入编译三份完整提示词。三个方案和测试组在一个savepoint中保存，失败不留下半组。

细纲版本、采用/审核，原著解析/来源选择、图谱、项目偏好及启用Skill变化，在预览、出队派发、晚返回候选和采用路径复核；原返回仍保存，过期候选不能当当前稿采用。已知模拟历史、参考或迟读会传播到组三方案与图像候选。图片字面内容的正确性须人工判断，结构校验和替身测试不能代替实际供应商质量验收。

每套复用agent_image_plans、image_jobs与原供应商调用登记，不自动审核或确认画风。测试图采用后普通重生成会清除旧测试组/方向/特征字段，只有本次明确属于测试组的任务才重新写入，避免把新自由单图冒认成旧测试板。

## 整组连续派发与恢复（2026-11-06）

后端已增加整组三张预览和严格授权接口，复用现有image_batches，不新增生产账本。页面可选择整组固定预览，一次明确授权后按A/B/C连续派发；暂停等待在途收尾，继续需重新勾选原范围授权。关闭面板不取消已授权批次。真实供应商质量仍未实测。

- POST `/api/projects/{pid}/agent/style-tests/{gid}/batch-preview`，严格空对象：准备A/B/C三个固定单图任务，再在事务中一起认领，未提交图像请求。已有任何方案拒绝、已提交、依据过期或关联他批时拒绝；重复读取同组不会再建调用。
- 返回的image_batches预览为mode=style_tests、count=3、images上限3/vision上限0，保存每项原call_id。三套均须尚未提交，不能把此前已经生成的单图装作一份新的三张授权。
- POST `/api/projects/{pid}/image-batches/{bid}/start` 或 `/recover`，均要求明确的 `{"confirm":true}` 授权；仅recover还支持严格的 `restore_only:true`，用于只登记已存原返回，任何prepared调用都不会派发（即便依据恢复有效）。缺字段、false、1或额外数量参数均拒绝。旧panels批次接口保持原协议。
- 沿既有批次pause/cancel/recover、四小时目标/七小时有效硬限、检查点和单图回执。暂停停止新派发并等在途收尾，取消保全已提交返回但不自动采用；未知请求不重发，重启不自动派发，恢复不清预算。整组认领后，单图start/recover不能绕过所属批次。
- GET原测试组可读关联batch；批次历史默认只列panels，`mode=style_tests`单独查询，避免现有图片工作区按话格误读。标识相同仍须同时匹配mode、组ID与固定input_hash，不能复用或关联另一范围的普通批次。
