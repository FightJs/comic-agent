## 实际验证

1. **画风预览、生成和采用。** 填名称/提示词后预览明确gpt-image-1.5、1张、1024x1536、固定prompt与无参考；API为prepared，无业务成品。再明确确认才返回候选。候选adopted0、不进主列表；采用后v2，再从详情明确确认画风。保存图片旁明确“尚未完成视觉复查、用量未知、金额未知”。
2. **资产画风绑定。** 自动转入资产页后，资产预览自动引用已确认画风v2。生成→候选→明确采用；原有文本资产仍保留。主列表显示AI来源与待审核，不把供应商返回当审核通过。
3. **重新生成与历史。** 资产详情重生成以目标v2为第一参考、画风v2为第二参考。返回时原资产仍v2，候选未采用；采用后目标v3，新旧文件URL和v1/v2/v3保留。版本审核抽屉可查看历史，嵌套抽屉可逐层关闭。
4. **真实替身未知返回。** 提示词标记使本机供应商返回500，页面显示“供应商结果未知，待核对”，没有自动重发按钮；同目标再预览被409阻止，输入保留。人工结论需要依据及确认勾选，提交后resolved，没有自动新建图片。此为隔离人工记录，不是对真实账单的核对。
5. **请求中取消。** 慢速替身等待4秒期间点击停止后续写入。API最终cancelled、call.completed，原URL保留而output_id为空，无候选。刷新历史后选择同项可查看已保存返回。
6. **已存返回的发布恢复。** 经主agent明确授权，匹配当前临时DB、pi-review与上述取消job/call，仅将job设interrupted、移除cancel_requested，未修改call/响应/图片/业务记录，构造“返回已存、候选未发布”。页面恢复成功，同call编号/原URL，call.updated仍为原值，形成未采用候选；已拒绝该测试候选。不是实际磁盘故障或崩溃复现。
7. **草稿保护。** 为目标设置浏览器临时未保存草稿标记，确认生成被可读alert阻止；标记已清理，没有提交供应商。
8. **长名称/长提示词。** 合法名称“边界验收-”加150个无空格A，在首审将整个grid撑宽：1280窗口drawer-body clientWidth804、scrollWidth1739。CSS修复后同一预览原位重查clientWidth804、scrollWidth804，标题748px内正常断行，长prompt内部纵向滚动。实际丢弃该未提交预览，再走普通生成→拒绝、关后重开历史，未见回退。
9. **能力提示及键盘。** 最终侧栏明确“逐格图像仍模拟”，项目库和助手说明画风/资产单图可连接模型、先保存提示词再去页面预览确认，未声称助手已触发生图。正常顶栏模型生图入口Esc恢复按钮焦点；详情版本审核的嵌套关闭正常。重生成入口焦点问题见一般项。

## 追加未知状态定点复审

最终后端加载后，用新临时数据分别检查，构造方式明确与真实重启分开：

- **unknown且无返回。** 创建新preview（未发供应商），核对临时DB与job/call绑定后，将两者状态设unknown，构造重启映射后的canonical状态。页面没有恢复按钮，人工表单可打开，核对依据为空/勾选未确认时按钮禁用；填写确认后resolved，无自动生图。未在本页面会话里实际杀死运行服务来复现startup映射，映射本身由主agent自动化单独证明。
- **unknown但已有原返回。** 新建慢速画风请求并取消，待call.completed且无业务输出后，仅在已核对临时DB将job/call置unknown、result置NULL、移除cancel_requested，保留原JSON/PNG。API公开has_saved_response=true；页面出现恢复按钮，点击后同call/同图片URL恢复为待采用候选。对原响应文件比较SHA与mtime，均完全不变，证明复用同一已存返回；没有声称发生了真实供应商故障。

这两条操作只修改人工构造的测试状态，没有访问真实data目录。最终服务中的一般生成/结果展示布局与上述修复未出现可观察回退。

一般项：

3. **重生成返回焦点。** 从详情点模型重新生成后，旧详情关闭、触发按钮被卸载；Esc退出新抽屉，浏览器实测open dialog=0、activeElement.tagName=BODY。建议显式回到当前资产卡片或稳定的模型生图按钮。正常顶栏入口实测能恢复按钮焦点，不混为全站焦点失效。
4. **核对确认排版。** checkbox在宽表单中居中、说明在下一行，视觉关联弱。建议对该确认label使用水平flex并限制checkbox与文案间距，保持整个label可点击和可访问名称。证据：`/tmp/pi-image-reboot-unknown-form-1280.png`。
