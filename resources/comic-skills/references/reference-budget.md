# 参考数量、同图多用途与忠实图集

原资料的五路径限制来自旧工具实测，不是所有图像API的通用上限。本移植保留五件套至多五份参考的创作预算，同时服从宿主更严能力；不能靠规则扩大参数能力。只有实际传入的图片才算参考，不是文件名、文字别名或库里有图。

提交前从批准镜头列出必要身份、当前衣装、画风、场景、真实前图像素及本次编辑底图，核对实际文件、内容hash、角色/状态、来源版本与用途。相同实际图片只带一次，保留全部允许用途；路径不同但hash相同先核对确为同图。同一人物不同衣装不能合并成同一状态，同图多用途不扩张任一用途的迁移许可。具体见[参考职责](reference-continuity.md)。

去重后仍超过预算，只暂停受影响格；不删除关键角色、衣装、场景或依赖，不用文字冒充第六张。优先足够清晰且批准用途齐全的多用途板。必要时可提出忠实技术图集方案：原批准图按真实像素裁区排布，保留每个角色/状态、原图hash、裁区、图集中位置和用途；不能重画未知设计、缩小到看不清或靠插值放大宣称清晰。当前宿主没有图集制作工具时仅给方案，不声称已拼装或验证像素。

忠实排布不是新设计批准，也不能自动成为画风权威。作为画风来源必须有对这张图集本身实际图像的独立适用批准，不能沿用其中子图的批准冒充整张图集已获该用途批准。裁区必须覆盖本格依赖的脸、衣装、衣领或可见首饰；同源hash但裁掉耳饰不证明携带细节。实际查看可辨识度，像素忠实不等于可辨；模糊原板不能靠锐化证明未知连接件。审阅站位图不是摄影机参考，不能为省槽混入身份图。

最终编号按真实提交数组重编译，提示词、项目生图包及宿主参数一致；不能只删数组第六项而保留旧“参考图6”。换参考或用途影响批准输入时，走现有版本/预览/授权关口，旧包和原调用保留历史。已保存原返回优先恢复登记，不重生。

数量/参数拒绝属于输入问题，无图不写成视觉失败；保留原调用状态，不自动增加修图轮次。明确拒绝且无图仍须依现有重新预览/启动路径处理，未知结果不得重发。数量与输入结构检查不代替身份、空间、实际看图或人工审核。
