# 一次真实剧情观察与必要修复边界

每张实际返回图默认一次快速剧情观察：主要人物是否明显错认，关键动作/对象/剧情信息是否缺失、相反或不可理解，必需场景背景是否被清成无结构纯色/白底。只在影响剧情判断的部位确实看不清时看必要局部/前图，不逐格放大饰品、指形、纹理或把全部MEM当固定表格；不加全话/跨话第二遍终审。普通细节原样留人工，轻审核的可读结论不等于全面精审全部PASS。

普通耳环、指形、衣装/画风/背景的轻微差异如实记位置、问题与正确目标；不可因美观追求触发自动返修。严重空背景与普通简化纹理不同：正文要求场景结构而整张纯白时必须记严重缺背景，不能用“有意虚化”解释，独立人物白底参考板则不套此要求。保留真实严重程度与分类，不把scene伪装story骗自动修复；它的处理建议不能因为当前自动阈值较窄而删掉。

本工作台现有批次自动返修只选择critical且category=story，并且用户预览选择review_repair、原预算及固定输入仍有效；其他身份/场景严重问题即使值得修，也须通过当前另行方案/人工入口，不能宣称本规则扩大了自动准入。建议范围保留主要人物错认、关键事件缺失、剧情相反/不可读和严重场景背景缺失；类别与是否自动触发分别描述，不强行改报告分类。

已授权自动返修仍最多一轮，只修达到当前真实准入的严重问题，其余留人工；不为了顺带小问题扩大目标。修后再看一次关键内容，无改善保留较可用版本与真实遗留问题，不自动第三轮。重大未解决仍标人工优先，不能改成全部可用；轻审核可“可读且带普通问题”，不能删FAIL或把未知调用当无图/失败后重发。

图像先保存原件/回执再释放生成资源，视觉检查独立排队；只有宿主实际实现的调度才可称并行或自动继续。讨论/检查报告不改人工审核或采用，候选仍需明确采用；旧来源关于qa-save自动采用不移植为权限。收尾核源格、文件可读、实际版本与必要证据，不假称当前已有极简ZIP/CSV封包器。

旧45分钟可选细化、10分钟接包、90秒编译、30秒观察/打包、8分钟或剩余30分钟修复降级，是原宿主实现的计时政策，当前未注册这些阶段定时器，不靠模型估时自动采用或放宽必需输入。现有批次4小时目标/7小时有效预算以宿主账本为准，服务等待计入、明确等待用户按实际策略处理，不因新进程/新话/换入口重置。到限保留已提交返回与问题，不能伪造源格齐全、文件有效或审核通过。

这些是当前轻审核的判断与建议资料；不执行旧生产脚本，不新增输出schema字段或硬件/模型速度承诺，不声称无真实对照已提升通过率。
