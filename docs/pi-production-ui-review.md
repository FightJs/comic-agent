## 已发现并复审解决的问题

1. **生图包对照对象错误（原重要）**：首次包将源脚本标为“原稿v2”，却只读其不存在的prompt而显示“—”；已有包也未优先对照固定原包。主开发已修改，刷新最新构建后实际复审首次包的源脚本十字段、已有包的五段/全文对照及390单列，原问题解决。
2. **长历史采用409反馈离操作太远（原重要）**：错误在抽屉顶部，点击下方采用后视口内看不到。主开发已改为每格就近ErrorNote；重新打开1280长历史并点击相同过期候选，错误实际出现在按钮前，390复查同样可见；候选未丢失，原问题解决。

## 保留一般问题

- **历史结果同话格标题缺少产物区分**：在“查看生成候选”中，脚本、首次包、重生成包都用“第2话·第1格/候选已生成”，需要继续阅读字段才能识别；未阻断采用与比较。建议标题附“脚本/生图包/修改”及时间或组名，避免多轮迭代历史中找错。证据：`1280-reopened-fixed-compare.png`与`1280-conflict-fresh.png`连续重复标题。
- **全局能力摘要仍较笼统**：首页“创作生成为模拟流程”、边栏“创作模拟”仍将创作统一概括为模拟；本轮范围生成明确写调用模型，任务中心与来源标记正确，故不构成本轮误触付费的主要路径阻断。建议后续统一更新全局摘要，区分已接入文本与尚模拟图像。证据：`1280-adopted-main.png`左下边栏与实际AI来源；刷新首页快照。
