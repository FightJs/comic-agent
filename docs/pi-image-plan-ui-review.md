## 问题与复审记录

### 重要

1. **已修复：关闭内层生图预览后焦点丢失。** 初版点击方案预览并完成生成后按 Esc，内层关闭但 document.activeElement 为 BODY。键盘用户失去上下文。建议关闭时聚焦当前仍挂载的方案预览按钮。开发修复后在 1280×800 与 1440×900，对待确认预览、历史候选和生成结果刷新三种状态重新操作，均返回 BUTTON“打开已有生图预览”，未再复现。
2. **已修复：资产属性发生 409 后没有可见的草稿恢复路径。** 上表真实并发条件下，资产详情只提供保存属性、版本与审核；重新保存仍用旧 expected_version，生成入口被正确禁用。AI 方案又正确阻止未保存草稿，但用户无法通过该详情读取最新后重试或放弃本地草稿，主要流程被卡住。建议复用 useDraft 的最新版本核对，并提供明确保留编辑／放弃草稿的操作，保留冲突输入且不静默覆盖新版本。证据：`1280-draft-conflict.jpg`、`1280-draft-guard-visible.jpg`，以及对应 AssetDetails/useDraft 逻辑辅助定位。修复后真实刷新并恢复原冲突缓存：1440×900点击“保留编辑并读取最新版本号”，原描述仍保留，明确提示点击保存才建立新版本；1280×800以 Enter 执行“放弃草稿并读取最新内容”，描述恢复服务端空值、状态已保存、生成按钮恢复。证据 `1440-keep-draft-recovery.jpg`、`1280-discard-draft-recovered.jpg`。未通过清除localStorage绕过恢复。

### 一般

G1. **预览错误可能落在当前视口下方。** 1280×800，长讨论滚到方案“创建生图预览”按钮靠近底部后触发草稿保护，错误追加在按钮下方，需要再滚动少量距离才看到；按钮仍可操作，文字反馈准确。影响是增加一次寻找反馈的操作，不妨碍恢复。建议仅在新错误出现时将对应错误区滚入可视区。证据 `1280-draft-guard.jpg`（点击后）与 `1280-draft-guard-visible.jpg`（向下滚后）；操作反馈扣1分。

G2. **放弃草稿成功后焦点没有落到剩余控件。** 1280×800，真实冲突缓存恢复后，以 Enter 执行“放弃草稿并读取最新内容”，操作成功、输入恢复，但该按钮消失后 AX焦点回页面主体。不会丢数据，但键盘用户需重新导航。建议成功后聚焦“资产描述”或“保存属性”，并保留已保存状态播报。证据 `1280-discard-draft-recovered.jpg` 与该次实际AX焦点0；键盘细节扣1分。此问题局限于新增恢复动作，不是已修复的内层抽屉焦点问题复发。
