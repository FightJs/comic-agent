- 模型是隔离替身，使用“【修改验收】”触发真实Pi SDK工具闭环；不能由此评价真实模型是否稳定理解用户自然语言、长篇小说语义或供应商用量成本。
- HTTP409由浏览器拦截模拟，确认的是前端错误及恢复体验。未保存草稿由隔离localStorage构造，未声称验证编辑器自动保存竞态。相应路由和临时草稿均已清除。
- 长内容为浏览器只读响应替换，未作为真实成品写入。大量记录、大数字、真实长篇、多目标复杂改写、创建/删除对象未验证，本轮实现是既有对象字段修改。

- 未运行屏幕阅读器或全站WCAG审计；未验证所有设备、所有色彩组合。390为本轮追加的助手容错检查，不宣称整个工作台已支持移动端。
