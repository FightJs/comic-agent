# Pi 手动暂停到安全检查点

原批准范围：完整Pi计划阶段六暂停停止新派发、保全在途返回，及阶段二准确分支明确续接。本增量不把未知调用伪装成已恢复。

1. Node pause仅作用于run，不作用于setup/complete。请求暂停后不再发送新模型/宿主工具；当前模型或已派发工具允许完成。下一个派发边界以manual_pause终止，保存paused/原会话/计数；若当前自然完整结束则completed。取消仍可强制结束。不能通过pause重新发送已有run。
2. 容量队列中的请求可移出队列并在无模型槽下创建start_paused的零调用SDK检查点；start_paused只做会话/账本，不发供应商。监督器必须保证取消/关闭优先，不把暂停当容量释放后重新发送。
3. 讨论/文本生产API先持久化暂停意图，queued/启动竞态均读取同一意图。真实未决回执不放行。生产保留两次结构尝试、原请求/来源/输入/预算；已有continue显式新增20/50授权，旧段计数不清零，不自动续接。
4. 本轮先实现与验证运行层及业务后端，界面入口和独立实页验收后续继续，不将API底座说成界面已交付。原完整goal保持active。
