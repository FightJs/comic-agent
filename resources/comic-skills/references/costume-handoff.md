# 衣装缺口、复用与跨话承接

读取[身份与状态](identity-confirmation.md)。本资料不运行旧选稿、衣装计数、资产发布或ZIP衔接脚本，不新建索引代替项目版本账本。

先核对当前采用的脚本版本和实际话格。文件名最新、目录顺序或未来话号都不是选稿依据；同话不同正文冲突先准确指出。未来脚本只用于已明确范围内的复用判断，不因此创建未来生产任务。保留场景、时间、对白中的换装线索。

按角色和衣装状态汇总当前真实需求一次：款式、颜色、层次、鞋履、配饰、伤势及身份锚点。每个需求绑定实际话格和源版本，不能只靠关键词或把样例写成事实。当前不需要的状态不为凑资产库而生图；缺失状态在当前授权范围提出最小增量资产候选，参考图实际保存后仍须明确采用和审核。脚本指定换装不能被旧资产覆盖，具体样式仍不能无依据猜测。

未来复用观察只计实际已读且确认可见、属于同一衣装状态的源话格；去重，同话格拼写变化不算额外出现。当前生产范围不重复算成未来出现；模糊、不可见、身份/衣装未知都保留未知，不把未知未来断言为一次性。已核定后续至少两格可见且同一状态时支持建议保存可复用资产，不自动授予发布或批准权限。

跨话承接记录当前角色、身份/衣装状态、适用起止范围、已知换装点、真实参考版本与未决项；下一话逐人核对当前脚本，不从某个局部增量断言已查完整资产库。衣装未知时保留已有可靠身份依据。不同分支或状态冲突只阻塞依赖项。发生换装从准确源格切换，不把整话所有格重写为新衣装。

相同已保存图片登记中断，优先按本系统原返回恢复，不重新生图；旧图哈希变化是冲突，不覆盖原件。当前工作台没有原ZIP/跨交接索引协议，不能宣称执行旧发布流程。用项目资产、来源版本、候选与审核状态承接。

独立人物衣装参考板使用全身主图加正、真侧、背三视图，头到鞋完整、纯白空白背景；临时参考也不降低可辨识要求。它是资产板规范，不能反过来要求每个正文格画全身或白底。没有实际四视图时只能提出制作方案，不能标为已核定。
