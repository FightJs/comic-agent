# 最终输入按原稿、实际参考和当前状态收敛

准备范围、设计可审、技术完整、已授权可调用与实图合格分别表述。只读查询或候选编译不授生成/采用/审核权限。沿原版本资料、候选与任务账本记录，不另造语义批准表，不热改旧包、复制旧PASS或重签旧摘要。

先读原稿当前瞬间和人物状态，再核身份/衣装/场景/画风的适用依据、机位及物理可行性、连续性、实际prompt/参考与观察目标。原文睁大、失焦等明确状态须原样表达，不能默认套眯眼、专注、闭嘴；沉默不等于闭嘴。保留准确文档/解析/版本/片段依据，摘要不是原文证据。过去状态不能混为当前事实，无法准确归属人物或否定/先后瞬间时阅读核实，不以关键词未命中证明无冲突。

逐人物区分脸可见、身份仍可辨、身体裁切及本格必要动作。后脑/肩背仍可辨身份时不能免掉身份衣装依据；面部局部可见只要求真实可见五官，不宣称不可见表情通过。胸上裁切却必显腰部、自然垂手或指尖时先修机位/范围，不为省事全扩全身，也不靠抬手改动作。多人可各有不同裁切下沿，接触与物件须容得下。

核对完整实际绘图文本，包括规则/参考说明、所有分段、完整提示词覆盖字段与观察要求：当前动作、状态、唯一机位、相机朝向、人物可见面/遮挡、裁切、必要背景、身体锚点和参考用途须同时一致。旧段仍要求相反状态时修对应来源和派生文字，不能在末尾追加更强相反命令。衣装共享不带入上一格站位；场景固定布局不混入上一格双手承托/本格人物动作。自然动物体表不套人体领口袖口；批准动物确实穿衣则依真实状态。疑点是阅读线索，不是自动FAIL或自动重签。

实际参考按当前内容、版本、顺序、角色/衣装/场景/画风/构图职责核对，不能只核文件名或目录已有图。引用地址改变与画面内容改变区分：确有内容一致证据时不重写无关设计；prompt、真实参考、机位、身份状态或检查目标变更则只复核受影响格和真实依赖，旧冻结输入不偷偷替换。更改相机/动作/取景须同步修可见性、配饰投影与有关文字，不能留旧投影签名。

全话保留完整源序与待补去向，先用本次真实代表格走实际候选入口，覆盖多人/配饰/裁切、连续空间及确有的跨话边界，再批量落实共性结构；不为样例填假设计或PASS，样例只证明该接口范围。全部静态准备与真正等待未来实图分别列出，缺身份/衣装/动作未定不能伪装前图依赖。只有确需前图像素才等待，不把普通比较关系变成硬生成依赖。

前图实际采用审核后补参考仍须核准内容、职责、顺序和实际新请求；允许槽不等于任意换图。返修输入已不同于首轮，修复目标、保护范围、实际底图和最终prompt须另核，原失败/返回/预算保留，不沿用初始摘要冒充已审。旧input_semantics、prepared_panel_inputs、候选编译/发布ZIP工具未因此实现；宿主固定预览和当前schema为准，没有正式封包验证不称正式整话交付。
