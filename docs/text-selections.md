# 条漫 Agent · 本机创作工作台

基础编辑、导入、审核、标注和下载真实可用。小说知识图谱接入配置的真实文本模型，扫描 PDF 可选 MinerU 解析；骨架/细纲、逐格脚本与生图包文本生产已接Pi模型调用；画风/资产与逐格单图已接模型生图预览及候选，单图视觉复查可明确调用模型并保存报告，连续批量编排仍明确模拟。

## 启动

在 Finder 双击 `start.command`，或在项目目录运行：

```sh
./start.command
```

浏览器打开 http://127.0.0.1:8765 。关闭服务终端或按 Ctrl+C 停止。只监听本机地址，不提供公网或账号服务。

首次启动需要 Node.js 22.19+、Python 3.11+ 和网络来安装依赖。启动脚本会安装独立 `agent-runtime` 的锁定依赖。若修改过前端，先运行 `npm run build --prefix frontend`，然后刷新网页。

开发时分别运行：

```sh
.venv/bin/python -m uvicorn backend.app:create_app --factory --host 127.0.0.1 --port 8765
npm run dev --prefix frontend
```

Vite 开发入口会在终端显示，API 请求代理到本地服务。

## 运行容量

各项目共用文本/图像/视觉容量，默认同时2/1/1个任务；等待后会再次核对取消、输入和模型配置。在项目库或项目内打开“模型设置”→“共享运行容量”可调整同时运行上限，保存后生效；冲突时保留输入，先核对再保存。此设置不是费用预算。接口与限制见 [`docs/runtime-capacity.md`](docs/runtime-capacity.md)。

## 使用

项目内可在“模型设置 → 项目创作偏好”或阶段AI助手中保存风格、节奏与表达习惯。只在明确保存后影响后续文本运行；支持编辑、删除、冲突核对和按项目保留未保存草稿。历史运行保留原快照，删除不会抹去旧对话；偏好不是原著事实或审核授权。操作与限制见 [项目偏好](docs/project-preferences.md)。

首次配置可在项目库或项目内打开“模型设置”，选择JSON配置包，核对用途、模型、地址和密钥动作后点击“应用这份配置”。可一次配置文本、生图、看图和PDF解析，密钥只写入macOS钥匙串；保存不代表连接已验证。格式与错误处理见 [`docs/config-packages.md`](docs/config-packages.md)。风格/流程Skill现可导入共享库并按项目启用，见 [`docs/skills.md`](docs/skills.md)；脚本执行适配及完整系统AI助手仍在实施。

1. 新建项目，导入 TXT、Markdown、DOCX 或 PDF。支持 UTF-8、GB18030；原件和解析版本保留，章节及证据可定位。解析后自动排队全文抽取与全书整理，配置缺失时等待配置，完整成功后统一发布图谱。
2. 在全书前期准备中编辑骨架与细纲，或通过“生成候选”调用模型、选择参考骨架并核对采用；“查看文档候选”可重开结果。细纲采用后建立对应话索引；原著须完整解析，未保存草稿会阻止生成。说明见 [`docs/document-generation.md`](docs/document-generation.md)。在知识图谱中切换剧情／资产视角及主干／完整／局部浏览，编辑人物状态与关系；导入画风和资产。画风/资产可点“模型生图（单图候选）”填写提示词并预览型号/参考，明确确认后才调用图像模型，结果核对采用后再审核/确认；详情支持重生成候选，旧稿保留。操作与未知结果核对见 [`docs/asset-image-jobs.md`](docs/asset-image-jobs.md)。模拟三套画风仍为独立演示入口。
3. 进入“脚本审核”，点击“从细纲选择话范围生成”。校正话号与细纲段落，选择起止话；已有脚本的话使用选格修改，不重复整话生成。先配置文本模型与密钥，按模型实际返回的格数生成待采用候选；缺少配置会明确阻止提交。结果中逐格核对、采用或拒绝，采用前不进入主表。
4. 完整11列表格支持按话/10话/全项目阅读。勾选连续多格，讨论修改意见；脚本/包批次讨论已接Pi并绑定所选话格版本，旧模拟对话保留为只读历史，图片批注讨论仍模拟。方案可明确填写或点击“将此回复加入生成方案”，再点“按方案生成候选”。同组结果集中比较、逐格采用，格号身份不变。“查看生成候选”可重开历史结果、查看模型返回和用量、取消运行或重试失败任务。过期输入候选不能采用。操作与边界见 [`docs/production-text.md`](docs/production-text.md)。
5. 生图包分别展示人物/场景资产及绑定版本、场景/内容/站位/分镜提示词与最终文本。可直接编辑或讨论修改；未保存草稿会阻止生成，手工覆盖完整提示词不会被分段编辑静默改掉。只勾选一格可点“模型生图（单格预览）”，核对固定包、话格和参考后明确确认；结果需采用才进入图片工作区，旧图版本保留。操作见 [`docs/panel-image-jobs.md`](docs/panel-image-jobs.md)。 多格可用“批量图像预览”核对并明确授权连续生成，常驻“批量图像任务”可重开历史；候选逐格采用，未知不重发，包详情可选择固定生成依赖包或已有审核前图；生成依赖包须一起选择，前图采用并审核后明确恢复原批次，独立格不受等待影响。单格入口仍不能绕过依赖，错误格式明确拒绝。见 [`docs/image-dependencies.md`](docs/image-dependencies.md)。见 [`docs/image-batches.md`](docs/image-batches.md)。 批次可选生成后实图检查及最多一轮严重剧情返修并复查；预览分别显示图像/视觉调用上限，原图与返修均需人工采用审核，未知不重发。见 [`docs/image-postprocess.md`](docs/image-postprocess.md)。 批次可暂停新派发，待在途返回保存后明确继续；四小时目标/七小时有效预算跨恢复累计，异常未知时间上界单独标明，到限不再派发。见 [`docs/image-batch-control.md`](docs/image-batch-control.md)。
6. 图片工作区整合多图缩略图、大画布和批注对话。点/框/画笔/保护区标记后就近输入建议，多个区域共同汇总；选择多图可写共同要求和逐格补充。发送讨论消息不会生成图片；工作区内批注讨论与“按方案生成”目前仍为明确模拟。真实单格图像从生图包预览授权入口生成。
单图生成结果、画风/资产详情或图片“资料与问题”可打开“模型视觉复查”：选择批准参考和脚本/包，可先读取并加入原著片段；预览固定引文、版本及已启用的审核Skill后明确检查一次，查看图片对照与问题依据。报告不替代人工审核，也不自动修图。未知调用先核对再记录结论；操作与恢复见 [`docs/vision-reviews.md`](docs/vision-reviews.md)。

7. 双指/滚轮平移，捏合或 Ctrl/⌘+滚轮缩放；按住空格或中键拖动平移，也可用工具条。历史图片使用独立标注；新旧候选逐格比较采用，失败项单独重试。单图与ZIP只下载原件。
8. “模型设置”可打开“AI 配置与流程助手”：附加规范JSON配置包或JSON/ZIP流程包，说明配置与安装要求；也可直接说“安装内置五件套”，不必先找文件；先查看具体变更，再逐项应用、安装及启用。没有文本AI时，可在助手中先直接导入启动配置包，无需逐项输入。模型配置对所有项目生效，Skill安装进入共享库，启用只作用当前项目；聊天不要粘贴密钥。项目内助手会读取本项目已启用的 setup 主规则及其包内引用资料；全局设置对话不继承项目规则。AI可按需查找已安装流程；历史的目录范围中可核对实际查询、固定版本及未读分页。会话、过期与冲突说明见 [`docs/setup-assistant.md`](docs/setup-assistant.md)。

8. “模型设置”中的“风格与流程Skill”支持JSON/ZIP规则包导入、查看主规则与按项目启用。下一次AI讨论及逐格文本生产按阶段加载固定版本，回复/任务保留所用流程；安装不自动启用、不执行包内脚本。跨包资料引用须声明精确版本依赖并在当前项目明确启用，缺项会保留选择并提示；可按ID/版本搜索依赖。 原条漫五件套已有可导入规则JSON与来源索引（当前1.0.0-pi.4，含18份参考、5份宿主元信息映射及首项受控只读画幅检查；安装升级后须明确重新选择版本），见 [`docs/comic-skills-migration.md`](docs/comic-skills-migration.md)；仍未完成旧脚本和批量执行器迁移。AI可按明确画幅方法核对固定整话主稿的比例分布，不自动改稿、采用或生图，见 [`docs/frame-plans.md`](docs/frame-plans.md)。
9. 在理解与记忆、骨架/细纲、画风/资产、脚本或生图包的顶栏打开“AI 助手”。先配置文本模型，可选择固定版本资料，询问原著、图谱及当前阶段信息并讨论修改方案。已发送会话可重开恢复，运行中可取消；未发送草稿在本次应用内保留，刷新/退出前请发送或复制。当前助手支持讨论、检索与结构化修改候选；先附加本阶段目标，再核对前后内容并明确采用，建立需要重新审核的新版本。助手不直接触发生图；画风/资产生图须另行预览并确认。范围和限制见 [`docs/agent-edits.md`](docs/agent-edits.md)。 原著整理完整发布后，助手可查询固定版本的卷章摘要、按章卷定位并核对原文；摘要是模型笔记，不是原文引文。来源和使用说明见 [`docs/novel-memory.md`](docs/novel-memory.md)。

本轮审查和限制见 `docs/batch-ui-review.md`、`docs/batch-code-review.md`；真实触控板硬件手感仍需实际使用反馈。

**模拟来源不会因编辑或改名变为正式来源。** 使用模拟引用的生图包和首话确认也保持模拟。模拟数据可演示流程，但不满足正式生产关口。

文本生产会在发送、结果登记与候选采用时复核本次参考的采用及审核状态；同版本撤销批准也会阻止旧候选覆盖，迟到结果仍保留供核对。见 [`docs/production-text.md`](docs/production-text.md)。

画风/资产AI助手可提出新建或重生成的具体生图方案：重生成先附加目标，展开方案后创建预览，再单独确认生成1张；原图保留，结果仍须采用。资产先确认已审核画风。操作与限制见 [`docs/agent-image-plans.md`](docs/agent-image-plans.md)。

骨架／细纲正文支持“选段 AI 修改”：先保存草稿、选择文字，再讨论并查看候选；只有“采用选段修改并保存”才建立新版本，原文改变会拦截，历史与来源保留。操作与精确范围限制见 [`docs/text-selections.md`](docs/text-selections.md)。

阶段助手、选段助手和文本生产结果卡已提供“暂停到检查点”：先停止新派发并等待已提交调用收尾，再核对检查点并明确授权续接；刷新保留待收尾状态。现有取消操作仍是取消，不要把取消记录当作可续接暂停，接口与限制见 [`docs/pi-run-checkpoints.md`](docs/pi-run-checkpoints.md)。

## 数据与安全

- `data/workbench.sqlite`：项目、文档、版本、审核、任务、标注及配置元数据。
- `data/files/`：导入的原始文档、PNG/JPEG 和模拟图片；文件不被覆盖。
- `data/agent/`：Pi 项目隔离会话，随完整 `data/` 目录备份。Pi 已接各创作阶段的讨论和只读证据工具，生产编辑与生成接入仍在实施；进度见 `docs/pi-progress.md`。图谱抽取和讨论共用Pi模型适配器，图谱使用无工具、无会话历史的单次调用；供应商回显的当前密钥在进入SDK会话前脱敏。未返回用量的请求明确标记总量未知。运行层不可用时基础编辑仍可用，`/api/agent/health` 不表示供应商连接验证通过。
- `data/agent/<project>/checkpoints/`：Pi讨论/文本生产的模型与工具调用登记，包含压缩请求用量，原编号不可重发。只读查询及限制见 [`docs/pi-run-checkpoints.md`](docs/pi-run-checkpoints.md)。阶段AI助手已支持无未决调用的额度暂停明确续接；新段另需授权20模型/50工具，保留原记录及未知用量，未发送意见不作为续接提交。文本生产结果页也支持干净额度暂停明确续接，仍用原任务/输入/分支且不增加结构修正次数；普通重试不能绕过。手动暂停、未决回执及其他生产故障恢复仍待接；备份时与会话、SQLite一并复制，不能靠删除账本恢复。
- 未保存编辑另在浏览器本地缓存，保存失败仍可恢复；恢复到不同服务器版本时提示冲突。
- API 密钥仅保存到 macOS 钥匙串。文本、生图、看图及解析用途各自保存配置；不返回已保存密钥，不写入 SQLite、普通本地存储、日志或下载包。
- 模型配置永远标为“未验证”。钥匙串不可用时明确报错，不退回明文。
- 单图下载和 ZIP 下载只包含所选采用图片的原件，不烧入标注、不携带密钥。

请勿删除 `data/`，它不是可再生成的缓存。本轮未提供项目备份包；需要手动备份时先停止服务，再复制整个 `data/`。

```sh

npm test --prefix frontend
```

## 本轮边界

知识图谱支持真实文本模型调用及可选 OCR，但本轮验收使用隔离替身供应商；未完成真实供应商联调或真实500万字全文理解质量验收。已实现图像协议与单图入口但未完成真实供应商生图联调；单图视觉复查已有实图输入与报告入口但未验证真实供应商效果；未实现模型连接测试；未实现 XLSX 模板、文档导出、账号协作、长条排版和绘画编辑器。模拟图片是明确标注的流程占位图，不是漫画生成效果样本。

技术：React / TypeScript / Vite / Tiptap / Canvas / d3-force / Konva；FastAPI / SQLite / Pillow / keyring。前后端依赖分别由 `frontend/package-lock.json`、`backend/requirements-lock.txt` 锁定。

知识图谱实施与验收：[`docs/graph/implementation.md`](docs/graph/implementation.md)、[`docs/graph/verification.md`](docs/graph/verification.md)、[`docs/graph/ui-review.md`](docs/graph/ui-review.md)。

脚本助手可提出新增格/删除格候选：先附加当前脚本，再明确采用。新增不重排旧格号；删除会同时撤下关联包、图片及试制确认，保留只读历史。操作边界见 [AI修改候选](docs/agent-edits.md)。
