## 无新资料对照

独立新上下文代理只读pi.3当前包和工作台合同，不读个人源资料，回答8题后才开始写pi.4正文。题目覆盖：双侧配饰总数/可见数/反打、双画面原格与电视、普通PNG/ControlNet、严重空白背景与宿主自动阈值、28格局部缺口、源稿状态与相反旧prompt、原尺寸戒指证据、返修退化后采用旧图。

对照已基本正确：

- 耳坠：“总佩戴数2保留在状态依据，不要求本图画出2枚。”并明确当前包没有总数/可见数专门结构字段，使用现有描述字段。
- 单画面：保留源格号和文字，必要信息放不下时列冲突，不擅自拆格；电视不能仅凭存在就判双格。
- 控制：“普通参考PNG上传只能证明参考图输入。”需要真实接口和请求证据，未知不编造。
- 背景：“人物剧情仍清楚时不能为触发自动返修伪造严重剧情问题。”指出旧包没有完整阈值映射。
- 就绪：局部缺衣装不扩大到全部独立格，真正像素依赖单列，完整交付须有真实全部去向。
- 冲突：“不能末尾加重一句新指令后保留相反旧块”。新输入不能继续挂旧hash。
- 像素：放大锐化不补原生信息，看不清留未知，不扩大为全套细节审查。
- 版本：“不能通过另开‘新首轮’重置已用返修次数”；首轮/返修各引用自身真实QA，不默认最新。

因此本轮不是“模型已失败→规则使其成功”的性能实验，不声称正确率、质量或速度提升。迁移依据是原计划要求逐项保留创作资料与来源，新增更具体的条件和可核对出处；没有为制造RED而把正确基线算失败。
