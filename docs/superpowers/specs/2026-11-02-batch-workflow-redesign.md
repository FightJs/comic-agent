# 批次制作重设计 · 用户已确认

## 目的与已确认选择
系统以 AI 完成生产、人工审核与指导修改为核心。本轮交付真实可用的交互和持久化数据流，模型调用仍为明确标注的模拟，下一步接真实 API。
用户已选择：完整11列表格审核；从细纲选择任意起止话生成；旧稿保留；批注可先与AI讨论，明确点击后才生成；多图共同要求加逐格意见；逐格采用新版；合并图片审阅与人工修改；生图包支持直接编辑和AI修改；脚本只修改选中格且保持身份，不提供整话重写；兼容鼠标和触控板。

## 方案选择
已选：三个连续工作区——脚本审核、生图包、图片工作区。保持当前话格、版本、筛选和阅读位置。
未选：保留四阶段会让审图与修改反复切页；逐格表单为主不适合完成品脚本审核。保留已有技术栈、存储与版本机制，重做批次制作信息结构及交互。
视觉沿用浅色资料区、深灰画布、克制橄榄强调色。使用者在桌面长时间审阅，画面占主要面积，按钮与辅助信息退居周边。参考用户Excel的审核密度、Codex的批注对话关联、常见设计工具的画布平移缩放习惯，不改为营销式界面。

## 1. 脚本审核
顶部：细纲来源/版本、起始话、结束话、生成脚本。范围不限10话，原有10话分组仅作为导航便利，不限制任务范围。
生成前显示选中话的标题、细纲全文、原著依据及可追加要求；固定输入版本，包含整部原著、骨架和细纲的引用。模拟返回只验证结构与流程，不声称根据原著真正创作。
细纲目前是自由文本：增加话级索引，以标题识别为初始建议，用户可校正话号、标题及对应段落；重复话号/缺话/未确定边界要定位并修正后再生成，不静默猜测。原文保持可编辑自由文本，索引绑定版本，改稿后重新核对映射。
主视图完整11列：格号、出现角色、当前场景、当前天气、当前时间、景别、机位角度、画面内容、台词、特效字、画面备注。固定表头与格号列，在表格内部横向滚动；长文本换行，不截掉台词和备注。按话分组，显示话标题和原著章节范围。原著引用未提供时如实显示未标注。
点一格打开可收起的阅读详情；默认阅读，不让每个字段都呈现输入框。可切换手动修订。审核支持一格、多格或整话通过；修改仅选择一格或多格（包括连续几格的场景问题），输入共同意见让AI修改。审核只绑定明确的所选版本。
修改使用整话上下文，但写入范围严格限定所选格。新增初稿允许各话不同格数；修改始终保留稳定格ID、格号及顺序，不增删格，不修改未选中格。不提供整话重写或重排话格功能。
修改候选稿逐格比较采用；同组修改结果同时展示，方便检查连续场景。采用新脚本后，旧生图包和图片保留，明确标记依据已过期，不自动重生成、不把旧审核继承给新稿。

## 2. 生图包
左侧按话格导航；主体为该格可阅读的生图包：
- 脚本摘要与所绑定版本。
- 人物资产：缩略图、名称、造型/状态、绑定版本、用途；场景资产同样展示。其他参考单列。
- 场景提示词、内容提示词、站位提示词、分镜（景别/机位/构图）、其他约束。
- 最终完整提示词：实际将提交的文本，可复制、可编辑。
- 执行参数、前图依赖及缺件信息。
各分段可直接修订，亦可输入意见让AI生成候选生图包。分段默认按确定顺序组合最终提示词；手工覆盖最终文本时明确标识，后续修改分段提示重新组合或保留覆盖，绝不静默使两者不一致。发送任务保存最终文本、分段和引用快照。
可多选话格生成生图包或图片。缺件按格列出，可仅提交就绪项，不能把未提交的格标为已完成。

## 3. 图片工作区（核心）
布局示意（1440px基准）：

    │ 按话缩略图 │ 格号 / 查看版本 / 采用版本  │ 批注与对话         │
    │ 筛选/多选  │                            │ 区域1 缩略/建议    │
    │ □ 第31话01 │         大画布             │ 区域2 缩略/建议    │
    │ □ 第31话02 │                            │ 整图补充要求       │
    │ □ 第31话03 │                            │ 对话输入框         │
    │            │ 工具 / 缩放 / 适应 / 1:1  │ 汇总发送 / 结果    │
    └────────────┴────────────────────────────┴────────────────────┘

进入图片工作区后折叠非必要全局导航，给画布空间。1280px可折叠缩略图/对话面板，不堆多重侧栏。对话打开仍保留可用画布。支持专注画布模式。
缩略图多选后出现共同修改要求和逐图意见列表；单图则呈现该图的区域批注和版本对话。多选与当前大图浏览互不混淆，明确显示发送数量及每图底图版本。
点或框选区域后出现紧邻目标、不会越出屏幕的简短输入框；输入修改建议后成为有编号的批注，右侧同时可见。允许多个区域建议、整图建议、保护区及画笔标记。取消未完成批注不会产生空记录。选择已有批注时关联区域高亮、可继续讨论或修改尚未发送内容。
对话与生成明确分开：点击“发送”只发讨论消息，可让AI澄清、整理和修订方案，不启动生图。讨论、批注及方案均持久化，模拟回复明确标识，不假装识别图片内容。点击独立的“按方案生成”才创建生成任务；创建前展示本次底图、选中图片、确认方案、区域批注、整图要求、共同要求和该格补充。每张图一个子任务。提交时冻结方案、会话消息范围、意见及底图，不随后续聊天或编辑改变。新消息不会自动加入正在运行的任务，可用于下一轮生成。结果显示在对话中，可点击新旧并排比较并采用；失败只重试失败项，成功项不重复发。
共同要求与逐格意见发生明显矛盾时由用户在发送前调整；界面同时展示两者，不偷偷取舍。模型实际判断留待真实API阶段。
批注绑定准确图片版本。换图不迁移区域坐标；历史对话仍可查，查看旧批注时明确显示所属版本。新图需要新批注，支持复制文字但不自动沿用区域。

### 画布手势（实施建议）
- 默认选择/批注模式；空格按住拖动临时平移，独立手形工具可持续平移，中键拖动亦可。
- 触控板双指滚动平移，捏合缩放；鼠标滚轮默认平移，Ctrl/Cmd+滚轮缩放。工具条加减、百分比、适应画布、1:1均可用。
- 根据滚动量平滑计算缩放并限制单次跳变，以指针位置为中心；不再每事件固定10%。不在输入框中拦截空格或快捷键。
- 点击缩略图默认适应新图；同图版本切换在尺寸一致时保留视角，尺寸变化适应新图。不改变历史标注坐标。
- 撤销重做只作用当前未发送标注编辑，不撤销已发送任务或采用操作；删除有明确选中目标。

## 数据与异常
任务统一保存输入快照：原著/细纲/脚本/资产/图片的ID与版本、所选话格、最终提示词、批注和会话。模拟任务沿用同一接口边界，结果始终带模拟来源。
任务在离开页面后继续；重启未完成任务标为中断，可显式重试。候选结果不自动替代采用版本。迟到结果进入原目标候选，不切走当前工作区，不覆盖编辑。
草稿（意见、包编辑、批注）自动持久化，保存失败和冲突保留本地内容。任务提交使用稳定提交标识防重复点击；部分成功逐项显示。无匹配、无图、无脚本、缺资产、过期依据均提供具体操作入口。
现有数据无损升级：原脚本字段直接映射11列，缺少话标题/依据不编造；旧完整提示词保留，不猜拆分。已有图片、标注、审核和历史保持可查。Excel仅作为示例依据，不擅自导入为业务数据。

## 验收与边界
独立子agent审查必须覆盖实际操作路径，并按这次用户目标验收，而非只检查布局和可点击性。
用示例同等密度数据检查完整11列、10话/至少295格、台词换行和画面备注；检查起止话、越10话范围、细纲缺话定位、选格重写不改邻格。
图片重点检查多区域对话汇总、多图共同/逐格意见、部分失败重试、版本比较采用、切版本不误绑；鼠标与触控板手势分别记录实际验证或未验证，不能用事件模拟声称真实手感。
覆盖1440px/1280px、200%缩放、键盘、持久化/冲突/重启。保留原项目隔离、模拟来源和正式关口测试。
本轮不接真实API，不验证模型质量/速度/费用，不实现绘图软件或长条排版。需真实图像时由用户导入；模拟图片只用于检查流程，不能展示为实际修改效果。
