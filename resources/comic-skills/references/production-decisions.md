# 真实问题、处理决定与采用版本

生产目标是可供人工继续加工的第一批逐格材料，不擅加气泡、排版、条漫拼接或第二/第三轮精修。沿同一候选、原返回、视觉报告和版本记录实际决定，观察不重复抄成第二份QA。问题类别与处理动作分开；程序核结构/引用不能声称识别画面错误。

重大类含主要身份、核心衣装/颜色、场景、画风、关键动作对象、主要连续性和明显多肢体归属/整体结构错误；规则/物理/配饰类按具体影响处理；普通指形、纹理或轻微衣装细节通常留人工。同图可多类，优先级取最高未解决影响，修不好不能降级。规则命中不等于必须重生，具体剧情影响、可定位程度、分布、调整范围、保留风险、修复历史与人工成本才决定建议。

批准依据正确但图偏差时，用适用批准参考提出修复；最终输入本身矛盾或机位/空间错误，先重建受影响输入并走当前候选/明确采用/预览，不重复原矛盾请求。整体空间错误不靠局部框掩盖。改变批准设计超出当前委托时列准确取舍，其他独立范围继续。当前自动返修准入以宿主定义为准，不能用重大类名替代真实报告分类。

一图一次合并必要修复，把已知问题分为本轮必须修、可顺带、明确留人工，互斥且有去向。普通轻微问题不自动进顺带清单扩大目标；实际prompt写准确纠正、保留、适用参考用途。改结构时明确旧错误结构移除、新结构和连接，不叠肢体。优先完成已授权独立格首轮，真正阻塞实图依赖的严重问题按原策略处理；普通格序不新增像素依赖。

局部编辑必须实际携带清晰正确的本格原底图；重生仍是原格修复尝试，不开新首轮重置一轮预算，错误图不升级身份/衣装/画风参考。返后原问题解决但有轻微剩余则留人工；无改善或整体退化停止该方法，比较历史候选，不因最新就采用。重复同因同法失败应保留根因及已停方法，有实质不同方案也须新准确范围与授权，强化“严格一致”不算不同方案。

选版本按未解决重大影响、核心一致性、清晰度/结构、人工接手成本综合，不默认最新或最早。首轮仅普通细节而返修改坏领口，优先考虑首轮为待采用/人工加工候选；采用首轮必须展示首轮自己的QA与剩余问题，不能套返修的结论。全部原图、有效修正、失败、未知调用、真实成本与原已耗额度保留；采用旧图不闭合另一未知请求。

问题说明用准确位置、实际问题→正确目标、确认/未核实、优先级与处理情况；已解决留历史，当前表述只对应实际所选版本，重大未解决置顶。没有图、坏文件、未知调用或必要观察未完成不是“无问题”。“可交人工加工”“人工优先处理”“仍不完整”不等于视觉合格或全部完成。

普通明确可留人工项不逐格再问；真实设计取舍、额外预算和用户保留审核点才集中提出推荐与准确待决范围。候选采用仍须本工作台明确操作，模型决定不能代签。旧自动qa-save采用、六列CSV、最终ZIP/交付审查编译器未迁，不能因为写了索引或决定就宣称完整成品包。新轻审核保留一次剧情观察，不恢复旧全话/跨话视觉复审。
