# 条漫 Agent · 本机创作工作台

基础编辑、导入、审核、标注和下载真实可用；AI 理解、编排、生图和复查全部明确模拟。没有任何真实模型调用。

## 启动

在 Finder 双击 `start.command`，或在项目目录运行：

```sh
./start.command
```

浏览器打开 http://127.0.0.1:8765 。关闭服务终端或按 Ctrl+C 停止。只监听本机地址，不提供公网或账号服务。

首次启动需要 Node.js 22+、Python 3.11+ 和网络来安装依赖。本机已完成安装。若修改过前端，先运行 `npm run build --prefix frontend`，然后刷新网页。

开发时分别运行：

```sh
.venv/bin/python -m uvicorn backend.app:create_app --factory --host 127.0.0.1 --port 8765
npm run dev --prefix frontend
```

Vite 开发入口会在终端显示，API 请求代理到本地服务。

## 使用

1. 新建项目，导入 TXT。支持 UTF-8、GB18030；原件只读，章节和前言可定位。
2. 在全书前期准备中编辑骨架与细纲，查看模拟关系，导入画风和资产。画风先审核，再在详情中选择采用。
3. 进入“脚本审核”，点击“从细纲选择话范围生成”。校正话号与细纲段落，选择起止话；已有脚本的话使用选格修改，不重复整话生成。模拟任务每话返回3格明确标记的结构样例。
4. 完整11列表格支持按话/10话/全项目阅读。勾选连续多格，讨论修改意见；方案需明确填写或点击“将最新意见加入方案”，再点“按方案生成”。同组结果集中比较、逐格采用，格号身份不变。
5. 生图包分别展示人物/场景资产及绑定版本、场景/内容/站位/分镜提示词与最终文本。可直接编辑或讨论修改；未保存草稿会阻止生成，手工覆盖完整提示词不会被分段编辑静默改掉。
6. 图片工作区整合多图缩略图、大画布和批注对话。点/框/画笔/保护区标记后就近输入建议，多个区域共同汇总；选择多图可写共同要求和逐格补充。发送讨论消息不会生成图片，只有“按方案生成”才创建任务。
7. 双指/滚轮平移，捏合或 Ctrl/⌘+滚轮缩放；按住空格或中键拖动平移，也可用工具条。历史图片使用独立标注；新旧候选逐格比较采用，失败项单独重试。单图与ZIP只下载原件。

本轮审查和限制见 `docs/batch-ui-review.md`、`docs/batch-code-review.md`；真实触控板硬件手感仍需实际使用反馈。

**模拟来源不会因编辑或改名变为正式来源。** 使用模拟引用的生图包和首话确认也保持模拟。模拟数据可演示流程，但不满足正式生产关口。

## 数据与安全

- `data/workbench.sqlite`：项目、文档、版本、审核、任务、标注及配置元数据。
- `data/files/`：导入的原始 TXT、PNG/JPEG 和模拟图片；文件不被覆盖。
- 未保存编辑另在浏览器本地缓存，保存失败仍可恢复；恢复到不同服务器版本时提示冲突。
- API 密钥仅保存到 macOS 钥匙串。文本、生图、看图用途各自保存配置；不返回已保存密钥，不写入 SQLite、普通本地存储、日志或下载包。
- 模型配置永远标为“未验证”。钥匙串不可用时明确报错，不退回明文。
- 单图下载和 ZIP 下载只包含所选采用图片的原件，不烧入标注、不携带密钥。

请勿删除 `data/`，它不是可再生成的缓存。本轮未提供项目备份包；需要手动备份时先停止服务，再复制整个 `data/`。

## 验证

```sh
.venv/bin/python -m pytest -q
npm test --prefix frontend
npm run build --prefix frontend
```

后端测试使用独立临时目录，不修改工作项目。前端测试覆盖坐标换算、来源筛选、迟到回复条件和草稿恢复/保存竞态。实际浏览器与独立子 agent 审查见 `docs/验收记录.md`。
