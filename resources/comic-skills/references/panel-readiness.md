# 完整源序、就绪范围与真实依赖

始终保留全话源格、顺序与准确版本，分别列设计可审/静态已准备、真正可提交、待补项、实际返回与已采用/已审数量。准备就绪不是付费许可，局部通过不是整话完成。不要为推进把待补格删掉或用“全话HOLD、正文0”掩盖其他就绪范围。

输入审计确认已读源稿与批准来源；视觉阶段复用适用身份、衣装、场景和画风，缺状态只阻塞使用该状态的格。镜头/包总览含完整源序，可先提出准确就绪范围的候选，待补范围列缺什么、为何影响及对应格，不索取空包批准。源序、共同画风、全局比例或共同身份来源错误才按真实共同范围阻塞；不能因一格局部缺口暂停所有独立工作。

设计尚未确定与真实图片尚未返回分别处理：前格站位、空间、动作或裁切未定时，真正沿用该设计的后格不能抢跑；只需同衣装/同场景连续或最后并排比较，不自动增加生成依赖。generation_dependencies只表示必须把前格实图送进本请求的真实需要，并按现有已采用审核和明确恢复入口执行。未知/坏文件/未返回图不能当参考，不能清空依赖或谎称新场景绕过。

上一话比较材料缺失不等于本话全部人物/空间未知。首格自身设计清楚时可随总览交讨论，但必须写尚缺边界比较；若该比较是本格必要放行依据，实际调用继续等待。后格确有独立、已批准且输入完整的本话依据时可继续，不能借首格候选当成正式批准。

例如28格，P1只缺必要跨话比较、P9缺其当前衣装，其余26格只有在各自输入、批准、依赖与授权都完整时才可提交；依赖P1/P9的格仍排除。设计审阅可以含准确待补说明，不冒充生成许可。全话完成仍须全部28格真实去向、实际原件与本次必要审核/采用和交付校验齐全。

补齐时保留旧包、旧候选及准确历史范围。只有本格及共同依据确未变，旧观察/批准才在其原范围适用；换机位、prompt、引用图、身份衣装或共同来源需复核影响项。只更汇总引用不等于每格改设计，也不能拿旧摘要替换新输入。不要为进度汇报重做同版本技术检查；观察结论不跨像素版本缓存。

旧readiness/bundle/compile命令、按范围HOLD标志与接包索引未迁成新工具。以工作台实际任务/候选/图像批次状态为准，不能假称已有自动就绪分类器、制作完整包或内部批准。轻审核仍一次真实剧情观察加必要局部，不恢复旧逐项/全话跨话第二遍视觉终审。
