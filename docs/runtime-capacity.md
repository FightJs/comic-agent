# Pi 共享运行容量

2026-11-06：共享容量后端与模型设置入口已实现；本轮独立页面审核及修复复审100/100，仅覆盖报告实测范围，证据见 `docs/pi-runtime-capacity-ui-review.md`。不是全局金额或 token 预算完成。

## 行为

- 一个应用实例共用文本、图像、视觉三个池，默认 `text=2 / image=1 / vision=1`。Pi 的讨论、配置助手、文本生产和图谱单次调用共用文本池；图像宿主及视觉服务分别使用对应池。视觉服务把本任务已取得的租约交给 Pi，避免同一任务重复占位。
- 同池先进先出。提高上限唤醒等待者；降低上限不取消已提交任务，等在途释放后再按新限派发。取消和健康检查不等待模型容量。
- 文本取得容量后重新核对业务任务状态、固定输入及公开供应商配置，再从钥匙串读取当前密钥。公开型号、地址或 API 类型变化会阻止提交；仅密钥轮换可以继续。配置助手把新密钥加入回显清理集合。
- 讨论核对明确附加的记录版本；文本生产复用已有完整输入过期检查；图谱分别核对原著来源/解析及细纲版本；图像与视觉保留已有最终提交前校验。已发送返回仍沿用原候选、用量和人工采用规则。
- 本层是单进程本机应用容量，不是多实例分布式调度，也不保证同池按项目公平轮转。配置不会改变单个上游服务已有局部调度上限（例如图谱同时两单元）。

## 页面操作

项目库或项目内打开“模型设置”→“共享运行容量”。三类任务显示当前运行/排队数和已保存上限；调整 1–8 后点击“保存运行容量”才生效。运行状态每3秒刷新，不会自动替换输入。PDF解析不计入这三类。

其他窗口修改设置时，会保留本窗口输入并显示最新已保存值。核对后可点击“已核对最新设置，保留我的输入”再保存，或“还原为当前设置”；不会自动提升草稿修订后覆盖。容量草稿存于本标签页sessionStorage，关闭设置或刷新后恢复；浏览器禁止存储时明确警告。读取失败不提供假默认值，已有数据标明为上次状态。

## 接口

`GET /api/runtime/limits` 返回 `revision`、三个 `limits` 及各池 `usage`（limit/active/waiting）。

`PUT /api/runtime/limits`：

```json
{"expected_revision":0,"limits":{"text":2,"image":1,"vision":1}}
```

三类数值必须都是 1–8 的整数，拒绝布尔值与多余字段。SQLite 保存修订；过期修订返回 409，不能静默覆盖。接口不接受或返回密钥。现有本机来源限制继续生效。
