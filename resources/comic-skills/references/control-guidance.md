# 实际能力、普通参考与结构控制

先查本次配置、可用工具/实际接口能力和固定输入，区分纯文字、普通图片参考、姿态/边缘/深度/分割等结构控制。上传普通PNG只是参考输入，不能推断已执行ControlNet或承诺逐像素一致；未知能力记未确认，不能虚构控制型号、强度或输入槽。本工作台当前没有登记结构控制适配器，不因本资料或参数文字存在就声称已运行。普通参考路线仍可形成有效候选包，不能因为没有不需要的控制图卡住正常参考方案；原身份、空间、脚本和授权缺口仍保留。

站位/俯视标注图用于讨论空间，带姓名、文字、箭头的审阅卡不能冒充目标相机视角的干净构图参考。必要且已有适用图先复用，不强制每格制作。干净构图图须符合批准机位、身体裁切、比例和可见关系，实际放入参考数组才可称携带；登记别名或看过库图不等于提交。没有选用构图参考就不留假槽，不强求站位图替代。构图图不能替代身份、衣装、画风和场景证据。

真正结构控制另需：本次可调用接口的实际能力证据；基础模型/控制模型及版本兼容；type、准确input_slot、预处理器/版本/参数、来源和真实像素尺寸。输入必须来自本格批准相机视角和身体范围，纯姿态/边缘/深度/分割数据不混审阅文字；不能对带字俯视卡估深度后称本场景深度。来源错不能靠提高强度补救，强度按实际后端试验，不给全书一个万能值。姿态不负责身份，深度不负责服装，边缘不证明遮挡语义。

计划有效、尚未执行、有真实调用记录、图片视觉正确四件事分别报告。真实结构执行需要可追溯请求/响应、实际送出的控制输入/型号/槽/参数与返回文件对应；有供应商request_id则保留真实值，没暴露不编造。普通参考记录真实prompt、参考顺序/用途、宿主attempt与原返回。日志一致只证明记录链，不认证供应商内部用了何算法，也不证明控制图几何或返回图正确。

旧控制检查脚本、预检/执行报告字段和模型训练算法未迁；不执行旧命令、不向当前schema塞control_inputs参数，不把NOT_RUN或历史未评估改成完成。新能力须由宿主另行实现与验证，旧冻结任务不热改。继续按实际关键动作、裁切、遮挡、身份及文字要求观察必要范围，不为此增加第二遍全图审查。
