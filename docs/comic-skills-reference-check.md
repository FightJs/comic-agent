# 首版条漫迁移规则参考检索小样

2026-11-05。目的：检查工作台移植包能否提供原规则中的具体答案及识别未适配合同。不是供应商实测，不是生产质量验收，也不是完整行为TDD或五次以上措辞实验。

结构TDD先于产物：`test_bundled_comic_skills.py`先因构建模块缺失实际失败；建立自包含包后验证导入、来源完整性与阶段读取。以下内容检索是产物形成后做的额外对照，不能倒称先有语义失败再写规则。

## 场景与样本

使用writing-skills明确要求的只读子agent测试，无资料样本`comic_rules_control`禁止读文件；有资料样本`comic_rules_reference_check`只读仓库内五份JSON入口、共享合同及所需MEM，不读取个人技能或其他产品说明。双方均答五题：临时人物衣装最低版式、相邻近景是否双变化、镜面反射及剧情冲突、未知超时下被催重发、普通瑕疵和临近截止。没有调用图片/文本供应商账户或写业务数据。

## 审查问题与修订

有资料样本真实指出：

1. MEM-004提到MEM-012，但包内没有该个人增补。
2. MEM-004的“全套图片质量及邻格连续性检查”与轻审核入口有解释张力。
3. MEM-010提到“已有格对例外合同”，没有工作台接口说明。

修订只新增工作台适用边界，11份MEM原文字节没有改动：个人增补明确不迁入、不读个人目录；旧“全套/重验”仅限实际命中及授权范围；例外只能在当前候选/报告保留依据，不虚构接口或批准。另明确正文实景背景规则不否定资产纯白四视图。

同一有资料样本重新读取重建后的五JSON，再答五题，并确认三处风险已明确限定；原答：“就本次五题及上述风险，未发现仍未限定的冲突。”这是同样本复查，不称全新独立复验或多次随机实验。
