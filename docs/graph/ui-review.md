### 一般 1：打开详情或缩窄窗口后，原有画布视口会裁掉节点

- 位置：理解与关系 → 节点列表 + 右侧详情。
- 复现：1440×1000 打开小图，再开列表/选择阿青并缩至 1280×900；也见于资产视角。
- 现象：保持原缩放和位移，部分节点在右侧或底部可视区域之外；有时选中节点在画布右部。
- 影响：需额外点击“适应画布”或“定位选中节点”；不丢数据，仍能完成任务。
- 建议：首次开启详情/列表时保持选中节点居中，或提供可见的“部分内容在视野外”适应提示；避免无条件打断用户主动平移。
- 证据：[02-detail-1280.png](../../output/graph-ui-review/02-detail-1280.png)、[04-assets-view.png](../../output/graph-ui-review/04-assets-view.png)、[21-state-assets.png](../../output/graph-ui-review/21-state-assets.png)。点击适应后局部图正常：[17-scale-local.png](../../output/graph-ui-review/17-scale-local.png)。

### 一般 2：默认小图中心多边标签相互遮叠，缩放后字号偏小

- 位置：12 实体 / 14 关系夹具默认主干图，阿青、林先生、白鹭会之间。
- 复现：1440×1000 初次打开，约 74% 缩放。
- 现象：中心“师徒/信任·推断/成员”等边标签接近并部分遮叠；节点副文字较小。
- 影响：快速看图不易分清中心关系；关系列表和关系详情能提供完整信息，因此不阻断。
- 建议：选中节点时对近距离边标签做避让，或仅展开相关边标签；保留列表作为准确阅读入口。
- 证据：[01-graph-1440.png](../../output/graph-ui-review/01-graph-1440.png)、[07-edge.png](../../output/graph-ui-review/07-edge.png)。
