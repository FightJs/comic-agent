## 实际验证

1. **无需文件的全局查询**：不附加文件，发送`【内置规则验收】安装内置五件套`，真实页面→Pi工具→本机替身生成5个独立安装候选。初始共享库为0、项目revision0/hash空；展开首项前5个安装按钮均禁用，首项核对后仅该按钮可用。候选准确展示“随应用提供的首版规则包；仅规则层，脚本与完整迁移未完成”，名称/版本/资料数/hash及长规则可读。[1440来源提示](/tmp/pi-bundled-origin-1440.png)、[1440核对与禁用](/tmp/pi-bundled-candidate-1440.png)，均已查看。
2. **安装不启用**：全局首项明确安装后，只读API确认共享库0→1；项目仍revision0/hash空。次项明确拒绝后没有新增安装。回执标明“查询来源：应用内置规则（查询不安装）”；本次冻结快照显示讨论时已安装库0，与后续安装状态分开。[查询回执](/tmp/pi-bundled-receipt-1440.png)已查看。
3. **项目安装前阻止启用**：项目内发送`【内置规则验收】安装内置五件套并启用`，得到5个安装候选及1个项目完整选择候选。核对后先点保存，真实隔离后端409阻止，错误“请先采用安装Skill候选，再启用本项目流程”自动滚入视口。[1280阻止反馈](/tmp/pi-bundled-blocked-1280.png)已查看。
4. **逐项采用后另行启用**：逐项核对/安装5份，其中已装首项幂等复用。API确认共享库5、项目仍revision0/hash空；五项成功均显示“已安装 · 未自动启用”。再明确保存项目选择后，API确认revision1/5个hash，与本次五候选一致。[启用前](/tmp/pi-bundled-before-enable-1280.png)、[启用成功](/tmp/pi-bundled-enabled-1280.png)，均已查看。五个hash分别为1df641…、b81d7b…、6c9465…、6ac0be…、e4ec13…，完整值保存在隔离运行回执中。
5. **已安装再查询及拒绝**：另建会话再次查询，核对并采用已装首项，共享库仍5、项目仍revision1/原5hash；拒绝次项不改选择，历史采用按钮相应消失。没有因重复采用自动增加版本或改项目。
6. **空结果修复**：新会话发送`【内置规则验收】空结果`，真实工具筛选无命中，候选数0。回执为“查询 无此规则：无匹配项。”，并保留“本次筛选无命中，不代表其他目录不存在”，不再显示0/0分页句式。[1280空结果](/tmp/pi-bundled-empty-1280.png)已查看。summary可聚焦并用Enter展开，橄榄绿内部焦点标记可见。
7. **旧字段与长内容**：浏览器只对GET会话响应构造无origin/source/available_bundles/catalog_library_total的旧结构，并加入119字符名称、192字符查找条件及长规则正文。旧记录不报错；安装来源提示不凭空补全，旧查询来源沿原已安装库语义显示，完整库数量明确未记录。1280/1440助手clientWidth/scrollWidth均748/748；正文714/714，280px高度内独立纵向滚动（scrollHeight8781），没有横向溢出或逐字竖排。[1280长正文](/tmp/pi-bundled-legacy-long-1280.png)、[1280旧回执](/tmp/pi-bundled-legacy-receipt-1280.png)、[1440旧长查询](/tmp/pi-bundled-legacy-long-1440.png)，均已查看。此项仅构造浏览器展示，未修改后台包或数据库；旧记录不可能原生含尚未提供的内置来源，因此不将移除来源字段解释为后端迁移实测。
8. **候选辨识修复复审**：首审一般项为五个未展开候选均只叫“安装共享Skill”，需要逐项展开才能识别。[修复前](/tmp/pi-bundled-multi-collapsed-1280.png)已查看。主开发修复后重新打开稳定页面，真实五标题在折叠状态直接显示职责名和版本，例如“安装共享Skill · 条漫 · 镜头与空间 v1.0.0-pi.1”。[1280修复后](/tmp/pi-bundled-title-fixed-1280.png)已查看。另浏览器构造119字符名+40字符版本，1280/1440均自然换行，748/748，无截字、遮挡或按钮膨胀；无name/version字段安全回退“安装共享Skill”，未显示undefined。[1280长标题](/tmp/pi-bundled-title-long-1280.png)、[1440长标题](/tmp/pi-bundled-title-long-1440.png)均已查看，原一般项关闭。
9. **返回及对比度样本**：两轮Esc实测均仅关闭助手，模型设置保持，250ms后activeElement为“AI 配置与流程助手”；关闭按钮固定。实际读取历史小字`oklch(0.46 0.012 115)`，浏览器canvas换算RGB88/89/81，对白底约7.09:1。未据此声称全站全部色对合格。
