# 整话按内容选幅与只读分布核对

适用于明确选择本方法的镜头或生图包方案，不强制覆盖其他风格流程、旧冻结任务或用户明确规格。先保留源格顺序、批准动作、最小充分裁切和必显信息，不能为比例配额搬家具、扩成全身、漏接触或改剧情。

从9:16、3:4、4:5、1:1、5:4、16:9逐格选择，并说明具体人物、动作、物件、空间方向或焦点为何适配。纵向动作/上下层次可考虑9:16，反应与上身动作用3:4或4:5，集中局部可用1:1，横向双人关系可用5:4，多组人物/横向场景可用16:9；这些不是固定模板，不写空泛“适合内容”。全身与画幅是不同决定。

content_balanced_ratios_v1：整话竖版（9:16、3:4、4:5）格数严格超过75%，1:1不计竖版；N格至少floor(3N/4)+1格竖版，30格至少23，35格至少27。竖组三种数量差不超过1；方/横组三种也差不超过1，小话可不用全六种。相邻格不同画幅，不能把方/横全堆末尾。源序前缀相对全话配额：方/横合计偏差不超过1格，单比例偏差不超过2格；容差不放宽总配额、相邻或竖版占比。不按六种各1/6分配。

先读当前冻结整话脚本和资产，按内容给一份候选计划；分批讨论不重置全话配额。源格、数量、版本、理由一起核对，内容与规格冲突时集中列具体格和取舍，不重排剧情、默认全9:16或随机改幅。校准/返修保持批准比例；改幅另形成准确范围的新候选，不能热改旧运行或重签旧批准。

当前受控工具：project_query action=frame_plan，id指定本次冻结的已采用脚本之一。先省略plan读取该话当前固定主稿集合的sources及源序；再传plan=[{id,ratio,reason}]严格同序覆盖全部sources，得到只读分布结果。候选/删除/未采用脚本不属于sources，旧运行无该冻结数据时工具拒绝，不从当前头版本补读。重复主格号也拒绝猜测。主稿集合并不证明原著已完整改编。

valid只说明所提交比例的数量/交错/分布和源序有效，不证明reason语义、动作可实现、镜头已采用或人工审核通过。工具不保存计划、不编译提示词、不检查实际图片、不发请求。修改仍走当前候选与采用入口。当前没有原CLI的状态文件、计划文件签署、自动output_spec或全话像素验收功能，不宣称原脚本完整迁移。

真实调用须核对模型实际支持尺寸，提示词写比例不等于有硬像素控制。返回应按实际宽高及批准容差核对单图和整话分布，计划多比例不能证明实际多比例；不放宽容差、反复重抽或裁掉必要信息冒充通过。需要真实图像核对而工具未提供时保留未验证，不把局部统计当整话完成。
