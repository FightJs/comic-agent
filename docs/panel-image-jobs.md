# 逐格生图包驱动的单图候选

2026-11-05单格增量记录；后续独立格连续批次已接入，见 `docs/image-batches.md`。完整Pi目标仍在实施。底层通过宿主OpenAI Images协议调用，自动化与页面均使用本机HTTP替身，未验证真实供应商权限、画质、一致性、费用或用量。

## 操作

1. 在逐格生图包保存完整提示词和参考，采用生成的包；绑定脚本须仍为当前且审核通过的版本。手工覆盖的完整prompt同样按实际保存内容使用。
2. 只勾选一格，点击“模型生图（单格预览）”。完整提示词只读；修改须关闭、保存包并重新打开。多选时按钮禁用，旧模拟批量入口保留明确标签。
3. 查看固定话格、包版本、图像型号、1张及实际图像参考。已有当前图时自动以其版本为替换目标；旧图像素不会因其为目标而暗中发送给供应商，参考只来自包。
4. 明确确认后生成未采用候选，核对图片再采用。首次采用建立话格图片；替换采用建立目标新版本，旧文件/旧版本及标注保留。图片工作区显示AI或继承的模拟来源，仍为未检查，不能当作视觉通过。
5. 未知、停止、原返回恢复和人工核对与画风资产共用同一入口，见 `docs/asset-image-jobs.md`。停止不保证撤销已发请求费用；恢复已存返回不会重新POST。

## 冻结与竞态保护

- `backend/panel_image_inputs.py`核对包完整prompt、话/格/批次、脚本身份及审核、包内实际已采用且审核通过的画风/资产图片版本。最多16张参考，不接受临时追加参考。
- 包、脚本、目标、参考head/采用指针/审核及当前话格图片占位均冻结；新主图、采用指针或版本变化均会拦截提交或采用。过期候选仍保留，不为获得新输入而自动重付费。
- 同话格未决调用按逻辑身份阻止绕过。目标/包/参考的模拟来源继承，真实协议不将模拟引用洗成正式来源。
- 容量槽等待结束后、请求进入submitting前再检查取消和全部冻结输入。排队中变更资料或取消，供应商不会收到请求。已存响应的恢复不重新执行网络提交。
- 图像配置与钥匙串凭据在配置锁内读取同一快照，提交前再核对配置，避免切换供应商时将新密钥发送至旧地址。这个保护也适用于画风/资产图像任务。
