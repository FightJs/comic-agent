# 参考职责与可变范围

将身份、当前衣装、动作、空间、裁切、画风分开。此方法受参考分离研究启发，但本工作台没有因此接入训练、特征缓存、ControlNet、区域mask或注意力控制；文字绑定不证明硬控制或多人模型能力。

每份实际参考说明角色/对象、固定版本、允许迁移与不得迁移，不能只靠图片次序认人。同一图可承担多个已核定用途，不另造重复上传。参考用途如下：

| 用途 | 可参考 | 不自动迁移 |
| --- | --- | --- |
| 身份 | 脸、头发、固定标记、批准体型 | 板上姿态、衣装状态、全身裁切 |
| 当前衣装 | 衣服、配饰、伤势状态 | 别人的脸、本格动作和机位 |
| 动作互动 | 姿势、接触、视线 | 检索图身份、服装、背景、裁切 |
| 场景视图 | 几何、材质、批准光向 | 板上人物、整幅宽景 |
| 构图 | 本格位置层级与裁切 | 占位人物身份、衣装、未知场景几何 |
| 空间布局 | 画面区域、纵深、遮挡 | 示意符号的长相、服装、画风 |
| 道具状态 | 形状、当前状态 | 持物者脸、无关姿态或背景 |
| 画风 | 线条、配色、明暗表达 | 示例剧情、人物身份和空间 |

灰阶无五官参考仍有体型/头发/衣装信息，不能自动作为身份来源；构图参考不顺带授权动作或几何变化。姿态图若造成换手、手机出画或改变接触结果就不适用，不能为了使用它改剧情。普通对话或已有足够依据不强制补姿态图；仅真实不可替代缺口才暂停相关项。

连续性按实际语义区分：同场景同视图核对可见锚点，姿态可按脚本变化；同场景新视图允许投影/遮挡变化，几何和实体位置保持；新场景用当前场景依据，不迁移上一房间家具；同场景状态改变必须有源稿依据，其他锚点仍固定。跨场景角色也保留身份/衣装，换衣只释放衣装，不顺带换脸。固定身份不等于冻结姿势。

本格必显项来自批准镜头，不能删掉关键接触/手机/文字/同时反应；画外人物保留连续性信息但不写成生成主体。实际可见头发仍承载身份，即使背面看不见脸也不能豁免。只见手或空镜按真实可见范围评价，不为不可见脸补无依据PASS；构图始终要核对，未采用额外构图图不等于免构图检查。

返回时分别说明身份、衣装、动作接触、背景空间、构图及画风的实际观察。一个接触FAIL不能被其余正确平均掉，未看清不是PASS。记录实际图与依据，结构检查只证明记录完整性，不证明已看图或用户已批准。沿现有视觉报告/人工审核，不创建旧六维QA或layout_release账本。

参考编号、用途与最终数组一致，预算见[参考预算](reference-budget.md)；动作与裁切见[取景](shot-framing.md)。
