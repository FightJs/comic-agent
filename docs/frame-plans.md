# AI整话画幅计划只读检查

2026-11-06。阶段AI讨论及文本生产的受控project_query现支持action=frame_plan。它是旧frame_ratio_plan.py的部分宿主适配，不执行上传包里的任意脚本，不保存/采用计划或生成图片。只有选择content_balanced_ratios_v1方法时使用该分布要求；不自动覆盖其他风格Skill、现有规格和旧冻结任务。

## 使用与边界

可在脚本或生图包AI助手要求先查询整话固定主稿、逐格按内容选幅，再核对分布。模型先调用project_query，action=frame_plan，id为本次冻结的已采用脚本之一；省略plan时返回该话sources，包含源格、id、version与来源。再传完整源序的plan数组，每项为{id,ratio,reason}。ratio为9:16、3:4、4:5、1:1、5:4、16:9之一；reason非空、最多2000字符。单话最多1000格，超过明确拒绝，不把分段当整话。

源序是该运行冻结的已采用主脚本集合：候选、已撤下、拒绝等不计。它不是原著完整改编证明，也不自动保证不存在尚未创建的格。相同话格有重复主稿时拒绝猜测；已采用主稿有非法话格号时保留阻断信息，同话或话号未知时拒绝整话核对。显式固定历史版本保留原版本，不因head更新而消失；冻结后新格和修改不会偷偷进入该运行。旧无此冻结字段的运行拒绝该操作，不补读当前源序。

提交计划必须按sources顺序逐一覆盖：漏格、重复、跨项目、重排均拒绝。其他project_query操作不接受plan参数。模拟主稿继续标mock；成功valid只说明数量/源序检查通过，不授予新权限。

## 数学规则

- 竖版（9:16、3:4、4:5）格数严格超过75%，至少floor(3N/4)+1，1:1不算竖版。
- 竖组三种数量差不超过1；方/横组三种也不超过1，小话可不用所有六种。
- 相邻格比例不同。
- 按全话配额检查源序前缀，单比例偏差最多2格，非竖合计最多1格，避免集中堆在末尾。使用整数公式，75%整点不会舍入成通过。

工具返回统计及结构化问题，不自动给各格选幅或改稿。选幅理由、裁切/动作可实现性需要内容判断；真实返回图片宽高、批准容差和实际全话比例尚未接入此检查。提示词写比例也不证明模型支持硬尺寸。必要比例修改仍须走现有候选、采用和图像预览授权流程。
