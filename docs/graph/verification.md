## 操作入口与配置

- 全书前期准备 → 小说原著：导入整本文件、阅读/全文搜索、章节校正、查看成图任务。解析完成自动抽取；在模型设置配置文本用途的 OpenAI 兼容 URL、model、钥匙串密钥。没有配置时保留等待任务。
- 全书前期准备 → 知识图谱：双视角与三种浏览方式、原著/当前改编、章节/话过滤、列表搜索、直接编辑、来源证据与图谱历史。保存使用 revision 检查；冲突保留草稿，明确重新应用后再保存。
- 确定当前细纲：选中一份正式细纲后自动同步，后续成功保存静默10秒合并排队。模拟细纲不能驱动正式图。
- 资产详情 → 图谱身份与参考用途：先核验当前画风与资产精确版本审核，再确认采用；身份变化后明确重新确认，图片版本保留，旧引用移除。
- 扫描 PDF：在模型设置的解析用途配置 MinerU；未配置或缺页时不会把不完整正文发布为完整图谱。

只在 `output/graph-review-data` 内进行验收，未改写正式 `data/`，未启动/替换8765正式服务。原工作区修改保留；没有提交或部署。
