# 衣装配饰锚点与一图单画面

用于实际命中的衣装、配饰、可见性和分格风险；沿现有资产、脚本/包及报告记录，不另建人物或首饰库。具体穿戴属于本书固定依据，不写成全局规则。旧运行保留原包，升级明确选择新版本。

先核对人物唯一身份、当前衣装状态及批准参考中的核心衣装：领型、袖长、开合、内外层、颜色/材质。没有服装也须有明确依据，不能从模糊或遮挡推定不存在。重要配饰单列人物/衣装归属、款式、总数量、角色自身左右、部位、身体/衣片锚点与连接；戒指明确哪只手和哪根手指。单件固定胸针不能漂到头发上；耳坠/项链可自然摆动，衣料可起褶，不因此换主人、侧别、数量或层数。模糊原板放大不产生新设计证据，未知款式/佩戴侧集中说明缺口，不默认对称。

总数是人物全身的总数量，不是每侧数量。另写本机位实际可见数量：总数2而只见自身左耳时，可见1；反打投影到画面右也仍是自身左耳。看不到的部分准确记遮挡或画外及其依据，不能为了展示配饰移位、转头或扩裁切，也不能宣称隐藏细节已核实。饰品确实摘戴、换手或换装须有源稿/批准状态变化，不给错误另起名字伪装一致。可见时区分身体锚点、当前画面位置、遮挡边界和连接；不得借他人的耳部当依据。

每格只绘一个连续取景的完整漫画画面，保留源格号、格数、顺序与原脚本文字。原格描述上下/左右多个完整画面时，选择承载关键动作、情绪或剧情结果的一幅，把选择理由及未绘画面留在方案，不新增格、不拆两张、不改成内嵌格。人物/动作/道具/必显信息须随选定画面一致；省略项不进入绘图指令。选择不能取消源稿必需文字或剧情信息，容纳不了时列准确冲突走现有候选，不擅改文字。真实电视、窗外、镜面或相框作为本场景物件不自动算第二格，也不能借此插入另一个独立叙事镜头；镜面仍服从本次MEM-008，不借示例允许真实倒影。

实际提示词写人物/当前衣装→款式数量→身体锚点/自身侧/手指→当前可见数量、投影与遮挡→单画面。每次生成/返修实际携带适用身份、衣装、画风及清晰细节参考，图集/局部须忠实覆盖原细节，不新画假参考，仍服从五份创作预算与宿主更严限制。失败图不能成为服装或画风权威。

返修把实际可见细节分为纠正/保留，互斥且覆盖，非服饰修复则现有正确服饰全部保留；明确不继承待修饰品/衣装错误，同时保住正确脸型、动作、光线、背景及先前有效修正。原一轮预算不变。真实观察先确认身体朝向和自身左右，再看必要原尺寸局部的款式、数量、锚点和附着；修好耳环却改坏衣领不能称全面正确。普通细节按本次轻审核范围留人工，不能因本文存在就每图逐项精审；看不清保持未验证。
