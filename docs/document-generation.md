# 骨架与细纲生成

骨架、细纲页提供“生成候选”“查看文档候选”。配置文本模型后，填写本次要求；细纲可显式选择参考骨架及固定版本，也可选择不引用。未保存的目标或参考草稿会阻止提交。当前原著必须完整解析；等待OCR的部分正文不能作为全书生成依据。

## 生成与采用

- `POST /api/projects/{pid}/production-jobs`：`operation=document`，`document_kind=skeleton|outline`，`refs`至多一个同类改稿目标，`basis`至多一个骨架参考（仅细纲使用），`submission_id`用于重复提交幂等。
- 骨架schema为标题和有标题/正文的分节；细纲为标题和递增、非重复话号的条目（话标题、正文、原著范围）。模型只能提交结构化文本，不能写HTML或审核字段。宿主转义标题/正文后生成HTML，不保留可能遮蔽新正文的旧text字段。
- 生产沿用独立Pi角色、只读资料工具、固定Skill资源、最多一次结构修正、回执、取消及来源继承。文档读取记录仅限当前原著、明确目标和所选骨架；选择不引用骨架时不能经工具隐式读其他骨架。所有文本生产都排除未采用/拒绝/待处理记录，范围脚本不再聚合这些骨架。新建和更新均先保存候选，采用前不改变当前文档或正式关口。
- 明确采用后创建未审核的新版本；细纲同时创建/更新绑定该版本的话索引。生成细纲正文从第N话标题开始，总标题只保留记录名，兼容图谱章话契约；未采用候选不能选择为正式改编图谱，采用后可明确同步。之后编辑正文会使旧索引过期，按话生成前必须再次校正保存。原著范围保存在索引中，不靠标题猜测恢复。
- 采用还要求成功生产回执与实际输出归属，不能手工拼装candidate_for覆盖原著或不同类型内容。原稿/参考/解析版本/所查图谱变化或切换原著来源时，旧候选保留供比较，不能覆盖当前内容。拒绝不改原稿，可再生成；运行中同类文档避免并发提交。

文档候选历史显示固定生成版本，采用/拒绝状态从当前记录读取；已有文档按固定原稿比较，首次候选可直接核对正文。旧text-only文档在编辑器、对照和版本记录中安全回退显示；已有HTML始终优先，即使为空也不复活旧text。真正编辑后移除旧text，防止图谱继续读影子正文。

旧`POST /tasks`的骨架/细纲模拟生成已拒绝；旧模拟文档任务不能直接重试为付费生产，须经新入口重新核对。编辑器“选段模拟修改”和旧批注讨论仍明确模拟；顶栏AI助手已有整篇修改候选，但精确富文本选段接入仍未完成。

## 原著来源与解析边界

文档生产使用当前成图来源`graph_source`；无来源选择时使用最新导入原著。仅该原著的文档/记录进入本次可读原著快照，历史不完整导入不会污染当前完整来源；来源选择也在采用时检查。

`project_query`的catalog、source和关键词检索都带固定解析版本的coverage：状态、已知完整性、警告和可读字数。即使检索无命中，也显示OCR/缺页状态和已搜索文档、起始位置。这里的complete仅表示该上传文件解析未报告缺页，不代表AI已经读完或理解全书。生成prompt仅带原著文档元信息，不重复塞全书目录；source只返回当前一万字范围的相关章节摘要（最多50条），不因全书数千章目录过大而无法分段读取。

章节校正保留OCR/缺页警告，新解析会取代旧等待OCR任务；不能用校正章节把扫描稿变为完整正文。可读PDF只有“未识别章节标题”时保持ready，不因此额外要求OCR。
