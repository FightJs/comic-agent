# 空间、可见范围与真实像素证据

只对实际命中、影响当前判断的空间/接触/细节风险取必要依据，不把旧全套表格加回每图轻审核。沿当前资产、镜头/包和同一视觉报告记录，不新增资产库或QA账本，未提供的像素不得声称已看。

来源先分物理子空间：同一酒店板的大厅、走廊、卧室不能因同资产ID混用站位。固定实体和关系只写批准参考确能证明的内容，必要时用相对区域/座位编号，不编厘米坐标；远处模糊人群不逐人设计。布局图复杂时才需要，现有图适用先复用，不每格强制重画。场景板多视图先明确本格对应视图与不能混入的邻近空间，缺所需机位依据不能靠裁图创造新几何。

同一连续场景切出去再切回仍承接该子空间最近状态；有源稿依据的时间/场景变化才重置。没台词不等于人物离场；画面左右的投影变化不等于世界换座。记录必要实体的当前位置、朝向、持续在场及移动/转向/离场的准确依据。可见、被谁遮挡、由哪条画幅边界排除、真正离场分别表达，不能删记录掩盖状态。只有必要实际前图比较才读取，比较关系不自动成为生成依赖。

重要服饰/配饰从清晰批准原板取得归属和锚点，真实原裁区看不清就留缺口，放大猜测不是新设计。实际图集若裁掉耳环所在来源区域，即使同原板hash也不能证明携带细节。画风、人物/衣装、场景和构图用途分别核对实际输入，单图多用途去重后仍服从五份创作预算与宿主更严限制。

真实观察先看主体、关键动作、人物持续在场、肢体归属与承托，再在剧情判断确有需要时看原尺寸局部，必要接触联合肩肘腕掌及作用对象。手/首饰/接触处露出且线清楚仍须核对具体target_part和动作阶段：扶前臂不是抓上臂，伸手靠近不是已握住，指向不是按下。局部裁掉接触点就不能判完整动作通过；实际遮挡不强求五指全露。批准景深、透视缩短和真实遮挡不自动是错误。

区分确认错误与证据不足。观察写当前真实图、对象/区域、实际结构及与批准依据的差异，不抄expected当observed。关键部位原图看不清时保留未验证，放大、锐化、重采样、PNG格式或填写更大尺寸都不增加原生证据。真实原尺寸区域必须来自原图、不过界且覆盖目标；当前接口未提供原生裁图时明确未执行，不编原尺寸审阅回执。

修图底图取本格已记录真实原返回，选择清晰、错误较少且携带有效修正的适用版本，不机械最新/最早。不用客户红字、缩略图或别格图替代底图。保护区绑定实际底图及尺寸，不用新图尺寸猜原图区域；返后比较保留项是否真保住，修好局部却损坏衣装/清晰度如实记录，不再追加自动轮次。批注坐标不是硬蒙版。

同像素、同依据的已有真实观察可按适用范围引用，前图换版只复核受影响比较；未知/未返回图不先记通过，独立格仍可继续。普通缺陷依轻审核留人工，不为本文取一套额外全图或跨话终审。旧原尺寸裁图、目标覆盖检查、像素图集认证与自动字段模板未迁，技术一致不认证几何或视觉正确。无真实配对前后生图不声称质量/速度提升；红字问题样本不是盲测。
