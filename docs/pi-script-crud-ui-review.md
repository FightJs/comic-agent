## 实际验证

1. 脚本审核 → AI助手 → 新建讨论 → 附加第1话第1格v1 → `【新增脚本验收】`。真实SDK产出待核对候选。采用前表格仍1格，候选明确“新增脚本 · 第1话第2格”、沿用话/批次、不重排及需审核；采用后表格2格，第1格仍v1，第2格v1待审核，来源AI。
2. 另建讨论附加第1格 → `【删除脚本验收】`。查看候选，实际展示删除前画面、原因及图片/生图包/脚本/试制确认四项版本列表，未出现图谱说明。
3. 在本浏览器为关联临时图片设置测试用未保存草稿标记，点击采用出现红色可读alert“目标仍有未保存草稿…”，没有删除。移除测试标记后再次采用成功；候选变已采用。
4. 关闭助手，脚本表只剩第2格，编号仍02；逐格生图包显示本范围尚无生图包；图片工作区显示0张及空态，未继续显示撤下图片。
5. 只读API核对被删脚本/包/图/试制确认均head v2、adopted0、deleted_by_script非空；各自v1仍存在且没有删除标志。第2格未被删除。历史核查为API证据，不声称存在已删记录专用历史导航界面。
6. 无附加资料新会话发送删除要求，收到“请附加一个当前脚本”，没有候选或业务写入。
7. 新会话附加第2格提出删除候选，点击拒绝后显示已拒绝、采用操作消失，第2格保留。
8. 再提出第2格删除候选，通过临时项目API模拟其他编辑者保存v2，回页面点击采用，真实409显示“脚本已有变化，请更新资料重新提出增删候选”，候选仍待核对且正文保留；API确认第2格v2、adopted1、无删除标志。
9. Esc关闭助手并恢复AI助手按钮焦点。常用按钮、资料勾选、可滚动抽屉、状态文字和长历史内错误均实际检查。未做完整读屏器认证。

## 一般问题（无阻断、无重要项）

- 候选标题如“第1话第1格 · 第1话第1格 · v1”重复位置。复现：展开增删候选；影响为局部阅读噪声。建议标题区分“参考格/删除目标”，位置只显示一次。证据：`/tmp/pi-crud-delete-details-1280.png`。
- 新增候选仍按通用差异显示“修改前 → 新建内容”，三字段重复同一说明。建议未来为新建用单列“新增内容”；不影响明确采用。证据：`/tmp/pi-crud-create-1440.png`及页面快照。
- 已删除脚本仍在新讨论附加资料选项中显示“第1话第1格 · v2”，未标明历史只读。建议保留历史查询但附上“已删除·历史只读”；当前宿主拒绝该记录的增删。证据：审核中第4次新讨论资料列表快照（临时`/tmp/pi-crud-snapshot.yml`曾记录，后被后续快照覆盖）；观察发生在第1格删除后，资料列表同时包含第1格v2和第2格v1。此项是实际观察，不是源码推断。
