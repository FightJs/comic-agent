# 逐格生图包表格调整
日期：2026-11-03。依据用户反馈：一次处理约五话，每话30格，主要使用表格。

## 本轮变化
- 原左侧格列表加右侧长表单改为主表格，默认五话范围，可指定起止话。
- 按话分组，整话或逐格选择；固定表头及话格列，表内横向滚动。
- 列展示状态、人物资产、场景/其他资产、场景/内容/站位提示词、分镜与完整提示词。默认紧凑两行，展开长文本可完整阅读。
- 详情按需打开抽屉，可上一格/下一格。关闭保持表格位置和选择，跨阶段也恢复。
- 状态筛选：缺提示词、有候选、脚本已更新；保留批量讨论和生成图片，补齐范围内缺少的生图包。
- 150格讨论的后端引用上限由100调整为300，与现有生成请求上限一致。大批量逐格补充折叠显示，避免挡住共同要求和生成操作。
